# 설비 모델 단순화 ②-b 프론트 정리 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** ② 로 다시 선 화면의 깨짐·어색함·현장에 없는 용어를 걷어 내, 실무자가 처음 봐도 막힘없는 화면으로 다듬는다(③ 전에).

**Architecture:** 데이터 모델·저장 경로는 그대로다. 화면 계층만 고친다 — 정보 구조(메뉴 셋), 용어(차단기·슬롯·실장 설비), 현황 도구줄·표, 상세 패널(차단기 목록 + 넓은 편집 창, 연결 목록 배치), 품목 표, 기준정보, 평면도 라벨. 마지막에 모든 화면을 브라우저로 다시 찍어 확인한다.

**Tech Stack:** React 18, TypeScript, Tailwind(시맨틱 토큰), vitest + Testing Library, Playwright.

**Spec:** `docs/superpowers/specs/2026-10-06-설비-모델-단순화-design.md` (§화면). 이 계획의 설계 결정은 2026-10-06 대화에서 사용자가 승인했다(아래 「확정 결정」).

## 확정 결정 (사용자 승인)

- **메뉴 셋:** 설비 현황 · **품목 관리** · 기준정보. 품목 관리 = 한 화면, 왼쪽 목록 `설비 · 랙 · 케이블 · 분야` 에서 고르면 오른쪽에 같은 편집 표.
- **용어:** 회로 → **차단기**(개수 입력 없음, 「차단기 추가」로 한 줄씩), 판 → **슬롯**, 안의 설비 → **실장 설비**.
- **품목 키:** 화면에서 숨기고 새 품목은 자동 생성한다.
- **기준정보:** 트리 패널을 걷고 `노임단가 · 제비율 · 올린 기록` 탭, 전체 폭.

## Global Constraints

- **UI 를 고치기 전에 `frontend/src/components/ui/CONVENTIONS.md` 를 먼저 읽고 따른다** — 본문 `text-sm`·라벨 `text-xs`(미만 금지), 시맨틱 토큰, 공용 컴포넌트 재사용(없으면 `components/ui` 에 더하고 index.ts·CONVENTIONS 에 등록), 크기는 prop, 행 액션은 호버, 표 크롬 고정·본문 스크롤, 삭제는 `tone="danger"` + `useConfirm`, IME 안전 확정 키.
- **화면 말:** 「종류」「자산」「회로」「판」「안의 설비」「키」를 화면 글자에 쓰지 않는다(코드 식별자 `circuit`·`panel` 은 그대로 둔다 — 모델 이름이다). 쓰는 말: 랙·설비·실장 설비·차단기·슬롯·코어·광선로·연결·품목·분야.
- 데이터 모델·API·저장 경로는 바꾸지 않는다(백엔드 변경 0). 차단기 = 모델의 `Circuit`, 차단기 수 = `circuitCount`, 슬롯 = `FiberLine.aPanel/bPanel`.
- 판정은 core 한 곳(`expandDeletes`·`validateState`·어휘). 화면에 규칙을 다시 쓰지 않는다.
- 프론트 타입체크 `npx tsc -b`(frontend/), 루트 빌드 `npm run build`.
- 개발 DB 는 이미 떠 있다(워크트리 `backend/.env` → `digital_simplify`). docker compose 금지. `git stash` 금지(임시 커밋 사용).
- 커밋 메시지 끝: `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. **좁은 상세 패널(364px)에서 글자가 세로로 쪼개지지 않는다** — 차단기·연결 목록은 한 줄 요약(넘치면 말줄임), 표는 넓은 창에서만. Task 3 시험(요약 행이 한 줄 레이아웃·편집 창 열림) + Task 6 스크린샷.
2. **차단기를 지울 때 연결이 남은 차단기는 지워지지 않는다** — 마지막 차단기 삭제는 연결이 있으면 까닭을 띄우고 아무것도 바꾸지 않는다. Task 3 시험.
3. **도구줄이 좁은 폭(1280px)에서도 두 줄로 넘치거나 표 머리에 가리지 않는다.** Task 2 시험(필터가 Select 하나) + Task 6 스크린샷(1280·1440).
4. **품목 새로 만들기에서 키를 묻지 않는다** — 자동 생성 키가 겹치지 않는다. Task 1 시험.
5. **화면 글자에 금지어가 남지 않는다** — Task 5 의 글자 검사 시험.
