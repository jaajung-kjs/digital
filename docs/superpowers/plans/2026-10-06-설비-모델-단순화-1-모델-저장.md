# 설비 모델 단순화 ① 모델·저장 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 포트·설비 품목 모델을 걷고 「랙 · 설비 · 회로 · 광선로(+코어·측정) · 국 내 연결」 모델로 DB·core·커밋 API·시드를 교체한다 — 끝나면 API 수준에서 데이터가 들어가고 여러 국에 걸쳐 원자 저장된다.

**Architecture:** 판정(검증·번호 행·삭제 펼침)은 `@twin/core` 의 새 `model/` 모듈 한 곳에 순수 함수로 둔다. 백엔드는 새 스키마 기준선 위에서 `PUT /api/v2/commit` 하나로 모든 엔티티를 받아 트랜잭션 안에서 적용한 뒤 **최종 상태를 core `validateState` 로 판정**한다(중간 상태 검증 없음). 시드는 마스터 + 직할 12국(광선로·코어·측정·랙·설비·회로·연결)을 커밋 서비스 한 번으로 넣는다.

**Tech Stack:** TypeScript, Node/Express, Prisma 5 (PostgreSQL, `backend/prisma/next/schema.prisma`, 클라이언트 `backend/src/generated/next-client`), zod, vitest, supertest, tsx.

**Spec:** `docs/superpowers/specs/2026-10-06-설비-모델-단순화-design.md`

## Global Constraints

- 판정은 `@twin/core` 한 곳 — 서버·프론트가 같은 함수를 쓴다(§6 서약). 서버에 검증 규칙을 따로 다시 쓰지 않는다.
- **종류 key 로 갈라지는 코드 0** — backend/src 에 설비·랙·케이블 종류 key 문자열 리터럴 금지(가드레일). 종류 key 는 `packages/core/src/seed/` 의 데이터 파일에만.
- 매체 어휘는 `CABLE_MEDIA` 한 곳: `power`(전원) · `comm`(통신) · `ground`(접지) · `fiber`(광선로). `fiber` 는 광선로에만, 나머지는 국 내 연결에만.
- 설비는 항상 랙에 든다(`Equipment.rackId` 필수). 랙 이름·설비 이름은 각각 국 안에서 유일(이름 공간 분리).
- 회로·코어는 **자연 키** — 회로 `(equipmentId, no)`, 코어 `(lineId, no)`. 행 생성·삭제는 `circuitCount`·`coreCount` 로만.
- 연결 끝은 정확히 한 종류(설비+표기 | 회로 | 코어 끝). 회로 끝·코어 끝마다 연결 최대 하나. 연결의 끝 대상은 만든 뒤 바꾸지 않는다(바꾸려면 지우고 새로 — 설계서에서 철거+신설이 맞다). 표기만 고칠 수 있다.
- 광선로 끝의 국은 만든 뒤 바꾸지 않는다.
- 삭제 펼침은 **클라이언트가** 한다(`expandDeletes`). 서버는 FK(Restrict)로 남은 참조를 거부한다(422 `DANGLING_REFERENCE`) — 서버가 말없이 연결을 지우지 않는다.
- 이번 단계는 **프론트엔드를 고치지 않는다**. 프론트의 옛 core import(`ASSEMBLY_GRID` 등)가 깨지지 않도록 옛 core 모듈은 지우지 않는다(②에서 지운다). 브랜치의 프론트는 새 API 와 맞지 않아 런타임에 동작하지 않는다 — 예상된 상태다.
- DB 는 리셋한다(현장 입력 데이터 없음 — 사용자 확인). 이관 스크립트 없음.
- 개발 규칙: DB 는 `docker compose -f docker-compose.dev.yml up -d` 만. `docker compose build`/`up` 금지. 빌드 확인은 `npm run build`.
- 커밋 메시지 끝에 `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- 코드 주석·메시지는 한국어, 주변 코드의 어투(「— 왜」를 적는 주석)를 따른다.

## Review Focus

1. **같은 커밋 안에서 만든 설비의 회로에 연결을 거는 경우** — 클라이언트는 회로 id 를 모른다. 자연 키 `(equipmentId, no)` 로 가리키고 서버가 설비 생성 → 회로 펼침 → 연결 생성 순서로 적용해야 한다. Task 7·8 테스트가 이 순서를 고정한다.
2. **회로·코어 수를 줄였는데 잘려 나갈 행에 연결·측정이 있는 경우** — 422 `ROWS_IN_USE` 로 거부하고 아무것도 바뀌지 않아야 한다. Task 7(회로)·Task 8(코어) 테스트.
3. **설비를 지우면서 그 설비·회로에 닿은 연결을 안 보낸 경우** — 서버가 연결을 몰래 지우지 않고 422 `DANGLING_REFERENCE`. Task 7 테스트.
4. **두 국에 걸친 광선로를 한쪽 국 사람이 고치는 동안 다른 쪽 국에서 같은 선로를 고친 경우** — 행 OCC 409. 광선로는 국 소유가 아니므로 소유 판정 없이 버전만 본다. Task 8 테스트.
5. **이름 겹침** — 같은 국 랙끼리/설비끼리 같은 이름이면 409 `NAME_TAKEN`, 랙과 설비가 같은 이름이면 허용(일체형). Task 7 테스트.

```ts
/**
 * 설비 모델의 **고정 어휘** — 표시·선택지·판정이 모두 이 파일만 읽는다.
 *
 * 매체는 사용자가 늘리는 것이 아니다: 「전원 트리를 무엇으로 그리나」, 「광선로에 쓸 수 있는
 * 케이블인가」가 이 값으로 갈린다. 케이블 **종류**(F-CV·OPGW…)는 관리자가 늘리고, 종류마다
 * 이 넷 중 하나를 고른다.
 */
export const CABLE_MEDIA = [
  { key: 'power', name: '전원', color: '#ef4444', use: 'link' },
  { key: 'comm', name: '통신', color: '#3b82f6', use: 'link' },
  { key: 'ground', name: '접지', color: '#eab308', use: 'link' },
  /* 광선로는 국 사이(또는 국 안 두 OFD 사이)를 잇는 **선로**다 — 국 내 연결에는 쓰지 않는다.
     광 점퍼코드는 국 안의 물리 케이블이라 `comm` 이다. */
  { key: 'fiber', name: '광선로', color: '#22c55e', use: 'line' },
] as const;

export type CableMedium = (typeof CABLE_MEDIA)[number]['key'];

/** 국 내 연결의 케이블 종류로 쓸 수 있는 매체인가. */
export function isLinkMedium(m: string): boolean {
  return CABLE_MEDIA.some((x) => x.key === m && x.use === 'link');
}

/** 광선로의 케이블 종류로 쓸 수 있는 매체인가. */
export function isLineMedium(m: string): boolean {
  return CABLE_MEDIA.some((x) => x.key === m && x.use === 'line');
}

export function cableMediumLabel(m: string): string {
  return CABLE_MEDIA.find((x) => x.key === m)?.name ?? m;
}

/** 설비 상태 — 철거 자체는 삭제와 변경 이력으로 남는다(「철거됨」 상태를 두지 않는다). */
export const EQUIPMENT_STATUSES = [
  { value: 'normal', label: '정상', tone: 'success' },
  { value: 'standby', label: '예비', tone: 'warning' },
  { value: 'fault', label: '고장', tone: 'danger' },
  { value: 'retiring', label: '철거예정', tone: 'neutral' },
  { value: 'replacing', label: '교체예정', tone: 'neutral' },
] as const;
export type EquipmentStatus = (typeof EQUIPMENT_STATUSES)[number]['value'];
export const DEFAULT_EQUIPMENT_STATUS: EquipmentStatus = 'normal';

/**
 * 코어 상태 — **물리 상태만** 적는다.
 *
 * 「사용 중인가」는 저장하지 않는다: 그 코어 끝에 연결이 있는가로 파생한다. 둘 다 적으면
 * 점퍼를 걷고 상태를 안 고친 코어가 「사용」으로 남는다(엑셀 선번장에서 실제로 그랬다).
 */
export const CORE_STATUSES = [
  { value: 'ok', label: '정상' },
  { value: 'broken', label: '단선' },
  { value: 'unusable', label: '사용불가' },
] as const;
export type CoreStatus = (typeof CORE_STATUSES)[number]['value'];
export const DEFAULT_CORE_STATUS: CoreStatus = 'ok';

/** 코어가 주 경로인가 예비 경로인가 — 선택 값. 그림에서 실선/점선을 가른다. */
export const CORE_ROLES = [
  { value: 'main', label: '주' },
  { value: 'backup', label: '예비' },
] as const;
export type CoreRole = (typeof CORE_ROLES)[number]['value'];

export const CIRCUIT_CURRENTS = [
  { value: 'AC', label: '교류' },
  { value: 'DC', label: '직류' },
] as const;
export type CircuitCurrent = (typeof CIRCUIT_CURRENTS)[number]['value'];

export const SWITCH_STATES = [
  { value: 'on', label: '투입' },
  { value: 'off', label: '개방' },
] as const;
export type SwitchState = (typeof SWITCH_STATES)[number]['value'];

/** 광선로의 두 끝. */
export const SIDES = ['A', 'B'] as const;
export type Side = (typeof SIDES)[number];
```

`packages/core/src/model/types.ts`:

```ts
import type { Side } from './vocab.js';

/**
 * 판정 함수들의 입력 — **판정에 필요한 칸만** 담은 행이다.
 *
 * 서버는 DB 행을, 프론트는 워킹카피의 effective 행을 이 모양으로 옮겨 같은 함수에 넣는다.
 * 이름·상태 같은 표시 칸은 판정과 무관해서 넣지 않는다(넣으면 두 쪽이 그 칸까지 맞춰야 한다).
 */
export interface RackRow { id: string; substationId: string; name: string }
export interface EquipmentRow { id: string; substationId: string; rackId: string; name: string; circuitCount: number }
export interface CableTypeRow { id: string; medium: string }

export interface FiberLineRow {
  id: string;
  cableTypeId: string;
  coreCount: number;
  aSubstationId: string;
  aEquipmentId: string | null;
  bSubstationId: string;
  bEquipmentId: string | null;
}

/**
 * 연결의 한 끝이 가리키는 것 — 셋 중 하나.
 *
 * 회로와 코어는 **자연 키**로 가리킨다(번호 행에는 id 가 없다). 그래야 같은 커밋에서
 * 만든 설비의 회로에도 바로 연결을 걸 수 있다 — 회로는 서버가 개수대로 펼치므로
 * 클라이언트가 id 를 미리 알 길이 없다.
 */
export type LinkEndRef =
  | { kind: 'equipment'; equipmentId: string; label?: string | null }
  | { kind: 'circuit'; equipmentId: string; no: number }
  | { kind: 'core'; lineId: string; no: number; side: Side };

export interface LinkRow { id: string; substationId: string; cableTypeId: string | null; a: LinkEndRef; b: LinkEndRef }

export interface ModelState {
  racks: RackRow[];
  equipment: EquipmentRow[];
  fiberLines: FiberLineRow[];
  links: LinkRow[];
  cableTypes: CableTypeRow[];
}

export type ModelIssueCode =
  | 'RACK_NAME_TAKEN'
  | 'EQUIPMENT_NAME_TAKEN'
  | 'EQUIPMENT_RACK_INVALID'
  | 'LINK_END_INVALID'
  | 'LINK_END_TAKEN'
  | 'LINK_SELF'
  | 'LINK_MEDIUM'
  | 'LINE_MEDIUM'
  | 'LINE_END_EQUIPMENT'
  | 'LINE_CORE_COUNT';

export interface ModelIssue { code: ModelIssueCode; message: string; ids: string[] }

/** 회로 행 키 — OCC 기준 버전·워킹카피 오버레이의 키. */
export function circuitKey(equipmentId: string, no: number): string {
  return `circuit:${equipmentId}:${no}`;
}

/** 코어 행 키. */
export function coreKey(lineId: string, no: number): string {
  return `core:${lineId}:${no}`;
}

/** 연결 끝이 가리키는 **대상**의 키 — 설비 표기는 들어가지 않는다. */
export function endRefKey(ref: LinkEndRef): string {
  switch (ref.kind) {
    case 'equipment': return `equipment:${ref.equipmentId}`;
    case 'circuit': return circuitKey(ref.equipmentId, ref.no);
    case 'core': return `${coreKey(ref.lineId, ref.no)}:${ref.side}`;
  }
}

export function sameEndRef(a: LinkEndRef, b: LinkEndRef): boolean {
  return endRefKey(a) === endRefKey(b);
}
```

```ts
/**
 * 번호 행(회로·코어)을 개수에 맞추는 계획 — **행은 늘 1..N 이다.**
 *
 * 개수가 행의 유일한 근원이다: 사람이 행을 하나씩 만들거나 지우지 않는다(엑셀 선번장도
 * 24심이면 24줄이 먼저 깔린다). 그래서 중간이 빠진 상태는 고칠 대상이지 보존할 사실이 아니다.
 */
export function rowsForCount(existing: readonly number[], count: number): { create: number[]; remove: number[] } {
  if (!Number.isInteger(count) || count < 0) throw new Error(`행 수는 0 이상의 정수여야 합니다: ${count}`);
  const have = new Set(existing);
  const create: number[] = [];
  for (let n = 1; n <= count; n++) if (!have.has(n)) create.push(n);
  const remove = [...have].filter((n) => n > count).sort((a, b) => a - b);
  return { create, remove };
}
```

```ts
import { endRefKey, type LinkEndRef, type LinkRow, type ModelIssue, type ModelState } from './types.js';
import { isLineMedium, isLinkMedium } from './vocab.js';

/**
 * 설비 모델의 **최종 상태**가 맞는가 — 판정의 유일한 자리.
 *
 * 서버는 커밋을 다 적용한 뒤 건드린 국의 상태를 실어 이것을 부르고, 프론트는 워킹카피의
 * effective 상태로 같은 것을 부른다. 중간 상태는 묻지 않는다: 랙을 바꾸며 이름을 맞바꾸는
 * 일처럼 한 커밋 안의 순서가 어긋나면 늘 걸리는 검사가 생긴다.
 *
 * 이름 겹침(①)과 끝 하나에 연결 하나(⑤)는 DB 유일 제약으로도 막지만, 화면이 저장 전에
 * 보여 주려면 여기에도 있어야 한다 — 같은 규칙을 두 군데 **적는** 것이 아니라 DB 는 마지막
 * 그물이다.
 */
export function validateState(state: ModelState): ModelIssue[] {
  const issues: ModelIssue[] = [];
  const rackById = new Map(state.racks.map((r) => [r.id, r]));
  const eqById = new Map(state.equipment.map((e) => [e.id, e]));
  const lineById = new Map(state.fiberLines.map((l) => [l.id, l]));
  const mediumOf = new Map(state.cableTypes.map((c) => [c.id, c.medium]));

  // ① 이름 — 국 안에서 랙끼리, 설비끼리 유일(이름 공간은 따로다).
  for (const [list, code, what] of [
    [state.racks, 'RACK_NAME_TAKEN', '랙'],
    [state.equipment, 'EQUIPMENT_NAME_TAKEN', '설비'],
  ] as const) {
    const seen = new Map<string, string[]>();
    for (const row of list) {
      const k = `${row.substationId}\u0000${row.name}`;
      seen.set(k, [...(seen.get(k) ?? []), row.id]);
    }
    for (const [k, ids] of seen) {
      if (ids.length > 1) {
        issues.push({ code, message: `같은 국에 ${what} 이름 「${k.split('\u0000')[1]}」이 ${ids.length}개 있습니다`, ids });
      }
    }
  }

  // ② 설비의 랙은 같은 국.
  for (const e of state.equipment) {
    const rack = rackById.get(e.rackId);
    if (!rack || rack.substationId !== e.substationId) {
      issues.push({ code: 'EQUIPMENT_RACK_INVALID', message: `설비 「${e.name}」의 랙이 같은 국에 없습니다`, ids: [e.id] });
    }
  }

  // ③ 연결의 끝은 연결의 국 안에서 끝난다.
  const endValid = (link: LinkRow, ref: LinkEndRef): boolean => {
    switch (ref.kind) {
      case 'equipment': {
        const e = eqById.get(ref.equipmentId);
        return !!e && e.substationId === link.substationId;
      }
      case 'circuit': {
        const e = eqById.get(ref.equipmentId);
        return !!e && e.substationId === link.substationId && Number.isInteger(ref.no) && ref.no >= 1 && ref.no <= e.circuitCount;
      }
      case 'core': {
        const l = lineById.get(ref.lineId);
        if (!l || !Number.isInteger(ref.no) || ref.no < 1 || ref.no > l.coreCount) return false;
        return (ref.side === 'A' ? l.aSubstationId : l.bSubstationId) === link.substationId;
      }
    }
  };
  // ⑤ 회로 끝·코어 끝은 연결 하나.
  const takenBy = new Map<string, string[]>();
  for (const link of state.links) {
    for (const ref of [link.a, link.b]) {
      if (!endValid(link, ref)) {
        issues.push({ code: 'LINK_END_INVALID', message: '연결의 끝이 이 국의 설비·회로·코어 끝이 아닙니다', ids: [link.id] });
      }
      if (ref.kind !== 'equipment') {
        const k = endRefKey(ref);
        takenBy.set(k, [...(takenBy.get(k) ?? []), link.id]);
      }
    }
    // ⑧ 두 끝이 같은 대상.
    if (endRefKey(link.a) === endRefKey(link.b)) {
      issues.push({ code: 'LINK_SELF', message: '연결의 두 끝이 같습니다', ids: [link.id] });
    }
    // ⑥ 국 내 연결의 매체.
    if (link.cableTypeId !== null && !isLinkMedium(mediumOf.get(link.cableTypeId) ?? '')) {
      issues.push({ code: 'LINK_MEDIUM', message: '국 내 연결에 쓸 수 없는 케이블 종류입니다', ids: [link.id] });
    }
  }
  for (const ids of takenBy.values()) {
    if (ids.length > 1) issues.push({ code: 'LINK_END_TAKEN', message: '한 회로·코어 끝에 연결이 둘 이상입니다', ids });
  }

  for (const l of state.fiberLines) {
    // ⑥ 광선로의 매체.
    if (!isLineMedium(mediumOf.get(l.cableTypeId) ?? '')) {
      issues.push({ code: 'LINE_MEDIUM', message: '광선로에 쓸 수 없는 케이블 종류입니다', ids: [l.id] });
    }
    if (!Number.isInteger(l.coreCount) || l.coreCount < 1) {
      issues.push({ code: 'LINE_CORE_COUNT', message: '코어 수는 1 이상이어야 합니다', ids: [l.id] });
    }
    // ⑦ 단자 설비는 그 끝의 국 설비.
    for (const [eqId, subId] of [[l.aEquipmentId, l.aSubstationId], [l.bEquipmentId, l.bSubstationId]] as const) {
      if (eqId === null) continue;
      const e = eqById.get(eqId);
      if (!e || e.substationId !== subId) {
        issues.push({ code: 'LINE_END_EQUIPMENT', message: '광선로 끝의 단자 설비가 그 끝의 국에 없습니다', ids: [l.id] });
      }
    }
  }
  return issues;
}
```

```ts
import type { LinkEndRef, ModelState } from './types.js';
import type { Side } from './vocab.js';

export interface DeleteRequest { racks?: string[]; equipment?: string[]; fiberLines?: string[]; links?: string[] }

export interface DeletePlan {
  racks: string[];
  equipment: string[];
  fiberLines: string[];
  links: string[];
  /** 지운 설비를 단자로 가리키던 광선로 끝 — 단자 설비·판을 비운다. */
  lineEndClears: { lineId: string; side: Side }[];
  /** 지울 수 없는 것과 그 까닭 — 화면이 그대로 띄운다. */
  blocked: { id: string; reason: string }[];
}

/**
 * 「이것을 지우면 무엇이 함께 가는가」 — **결정적인 한 규칙**.
 *
 * 펼친 결과는 워킹카피에 그대로 들어가 사람 눈에 보이고, 설계서에 철거로 잡힌다. 서버는
 * 이 펼침을 다시 하지 않는다: 남은 참조가 있으면 FK 가 거부한다. 서버가 말없이 연결을
 * 지우면 화면이 보여 준 설계서와 저장된 것이 달라진다.
 *
 * - 설비 → 그 설비·그 설비의 회로에 닿은 연결. 그 설비를 단자로 가리키던 광선로 끝은 비운다.
 * - 광선로 → 그 선로 코어 끝에 닿은 연결(양 끝 국 모두).
 * - 랙 → 안에 남는 설비가 있으면 막는다.
 */
export function expandDeletes(state: ModelState, req: DeleteRequest): DeletePlan {
  const eqGone = new Set(req.equipment ?? []);
  const lineGone = new Set(req.fiberLines ?? []);
  const links = new Set(req.links ?? []);

  const touches = (ref: LinkEndRef): boolean =>
    (ref.kind === 'equipment' && eqGone.has(ref.equipmentId))
    || (ref.kind === 'circuit' && eqGone.has(ref.equipmentId))
    || (ref.kind === 'core' && lineGone.has(ref.lineId));
  for (const l of state.links) if (touches(l.a) || touches(l.b)) links.add(l.id);

  const lineEndClears: DeletePlan['lineEndClears'] = [];
  for (const l of state.fiberLines) {
    if (lineGone.has(l.id)) continue;
    if (l.aEquipmentId !== null && eqGone.has(l.aEquipmentId)) lineEndClears.push({ lineId: l.id, side: 'A' });
    if (l.bEquipmentId !== null && eqGone.has(l.bEquipmentId)) lineEndClears.push({ lineId: l.id, side: 'B' });
  }

  const racks: string[] = [];
  const blocked: DeletePlan['blocked'] = [];
  for (const rackId of req.racks ?? []) {
    const left = state.equipment.filter((e) => e.rackId === rackId && !eqGone.has(e.id)).length;
    if (left > 0) blocked.push({ id: rackId, reason: `랙 안에 설비가 ${left}대 있습니다 — 먼저 옮기거나 지우세요` });
    else racks.push(rackId);
  }

  return { racks, equipment: [...eqGone], fiberLines: [...lineGone], links: [...links], lineEndClears, blocked };
}
```

```ts
/**
 * 마스터 — 분야·랙 종류·설비 종류·케이블 종류. **넷 다 단순 표**다.
 *
 * 옛 카탈로그는 포트 템플릿·구성 그리드·내부 결선을 안고 있어 한 종류를 고치는 데 구조
 * 검사(TYPE_IN_USE 의 구조 변경 판정·accepts 정규화)가 따랐다. 이제 종류는 이름과 품셈뿐이라
 * 「쓰이는 중이면 못 지운다」 하나만 남는다.
 */
import { CABLE_MEDIA } from '@twin/core';
import { Router } from 'express';
import { adminOnly, authenticate } from './auth.middleware.js';
import { catalogBodies, catalogPatches, CATALOG_KINDS, type CatalogKind } from './catalog.schemas.js';
import { isPrismaError, nextDb } from './db.js';
import { HttpError } from './errors.js';

export const catalogRouter = Router();
catalogRouter.use(authenticate);

interface Delegate {
  create(args: { data: object }): Promise<unknown>;
  update(args: { where: { id: string }; data: object }): Promise<unknown>;
  delete(args: { where: { id: string } }): Promise<unknown>;
  findUnique(args: { where: { id: string } }): Promise<unknown>;
}

/** 종류마다 다른 것은 델리게이트와 「무엇이 쓰고 있나」 셈뿐이다 — 테이블 값으로만 가른다. */
const KINDS: Record<CatalogKind, { delegate: () => Delegate; usage: (id: string) => Promise<number> }> = {
  categories: { delegate: () => nextDb.category as unknown as Delegate, usage: (id) => nextDb.equipmentType.count({ where: { categoryId: id } }) },
  'rack-types': { delegate: () => nextDb.rackType as unknown as Delegate, usage: (id) => nextDb.rack.count({ where: { rackTypeId: id } }) },
  'equipment-types': { delegate: () => nextDb.equipmentType as unknown as Delegate, usage: (id) => nextDb.equipment.count({ where: { typeId: id } }) },
  'cable-types': {
    delegate: () => nextDb.cableType as unknown as Delegate,
    usage: async (id) => (await nextDb.link.count({ where: { cableTypeId: id } })) + (await nextDb.fiberLine.count({ where: { cableTypeId: id } })),
  },
};

function kindOf(raw: string): CatalogKind {
  if (!(CATALOG_KINDS as string[]).includes(raw)) throw new HttpError(404, 'NOT_FOUND', '없는 목록입니다');
  return raw as CatalogKind;
}

catalogRouter.get('/catalog', async (_req, res, next) => {
  try {
    const order = [{ sortOrder: 'asc' as const }, { name: 'asc' as const }];
    const [categories, rackTypes, equipmentTypes, cableTypes] = await Promise.all([
      nextDb.category.findMany({ orderBy: order }),
      nextDb.rackType.findMany({ orderBy: order }),
      nextDb.equipmentType.findMany({ orderBy: order }),
      nextDb.cableType.findMany({ orderBy: order }),
    ]);
    res.json({ categories, rackTypes, equipmentTypes, cableTypes, media: CABLE_MEDIA });
  } catch (e) {
    next(e);
  }
});

catalogRouter.post('/catalog/:kind', adminOnly, async (req, res, next) => {
  try {
    const kind = kindOf(req.params.kind);
    const body = catalogBodies[kind].parse(req.body);
    res.status(201).json(await KINDS[kind].delegate().create({ data: body }));
  } catch (e) {
    next(isPrismaError(e, 'P2002') ? new HttpError(409, 'KEY_TAKEN', '같은 키가 이미 있습니다') : e);
  }
});

  try {
    const kind = kindOf(req.params.kind);
    const patch = catalogPatches[kind].parse(req.body);
    const d = KINDS[kind].delegate();
    if (!(await d.findUnique({ where: { id: req.params.id } }))) throw new HttpError(404, 'NOT_FOUND', '해당 종류를 찾을 수 없습니다');
    res.json(await d.update({ where: { id: req.params.id }, data: patch }));
  } catch (e) {
    next(e);
  }
});

catalogRouter.delete('/catalog/:kind/:id', adminOnly, async (req, res, next) => {
  try {
    const kind = kindOf(req.params.kind);
    const { delegate, usage } = KINDS[kind];
    const d = delegate();
    if (!(await d.findUnique({ where: { id: req.params.id } }))) throw new HttpError(404, 'NOT_FOUND', '해당 종류를 찾을 수 없습니다');
    const used = await usage(req.params.id);
    if (used > 0) throw new HttpError(409, 'TYPE_IN_USE', `${used}건이 이 종류를 쓰고 있어 지울 수 없습니다`);
    await d.delete({ where: { id: req.params.id } });
    res.status(204).end();
  } catch (e) {
    next(e);
  }
});
```

```ts
const linkPatch = z.object({ ...linkFields, aLabel: text, bLabel: text });

/* ── 기록 ── */
const recordOps = <S extends z.ZodRawShape>(shape: S) => z.object({
  creates: z.array(z.object({ id, equipmentId: id, ...shape })).optional(),
  updates: z.array(z.object({ id, patch: z.object(shape).partial() })).optional(),
  deletes: z.array(id).optional(),
}).optional();

export const commitPayloadSchema = z.object({
  floors: ops(floorCreate, floorPatch),
  racks: ops(rackCreate, rackPatch),
  equipment: ops(equipmentCreate, equipmentPatch),
  circuits: z.object({ updates: z.array(circuitUpdate).optional() }).optional(),
  fiberLines: ops(fiberLineCreate, fiberLinePatch),
  cores: z.object({ updates: z.array(coreUpdate).optional() }).optional(),
  coreMeasurements: ops(measurementCreate, measurementPatch),
  links: ops(linkCreate, linkPatch),
  records: z.object({
    maintenance: recordOps({ occurredAt: z.string().datetime(), content: z.string().min(1), action: z.string().nullish() }),
    inspections: recordOps({ inspectedAt: z.string().datetime(), content: z.string().min(1), result: z.string().nullish() }),
    /* 사진 경로는 클라이언트가 정하지 않는다 — 파일이 요청에 함께 오고 서버가 이름을 짓는다. */
    photos: recordOps({ caption: z.string().nullish() }),
```

```ts
import { HttpError } from '../errors.js';
import type { CommitPayload } from './schema.js';

type Tx = Prisma.TransactionClient;

/**
 * 이 커밋이 건드리는 국 — 만드는 것은 페이로드가 국을 적고, 고치고 지우는 것은 DB 에서 읽는다.
 * 광선로는 **두 끝 국 모두**다(두 국이 같은 행을 공유한다).
 */
export async function touchedSubstations(tx: Tx, p: CommitPayload): Promise<string[]> {
  const ids = new Set<string>();
  const add = (s: string | null | undefined) => { if (s) ids.add(s); };
  const idsOf = (o?: { updates?: { id: string }[]; deletes?: string[] }) =>
    [...(o?.updates ?? []).map((u) => u.id), ...(o?.deletes ?? [])];

  for (const c of p.floors?.creates ?? []) add(c.substationId);
  for (const c of p.racks?.creates ?? []) add(c.substationId);
  for (const c of p.equipment?.creates ?? []) add(c.substationId);
  for (const c of p.links?.creates ?? []) add(c.substationId);
  for (const c of p.fiberLines?.creates ?? []) { add(c.a.substationId); add(c.b.substationId); }

  const recordEquipment = [
    ...(p.records?.maintenance?.creates ?? []), ...(p.records?.inspections?.creates ?? []), ...(p.records?.photos?.creates ?? []),
  ].map((r) => r.equipmentId);
  const [floors, racks, equipment, links, lines, lineIdsFromRows] = await Promise.all([
    tx.floor.findMany({ where: { id: { in: idsOf(p.floors) } }, select: { substationId: true } }),
    tx.rack.findMany({ where: { id: { in: idsOf(p.racks) } }, select: { substationId: true } }),
    tx.equipment.findMany({
      where: { id: { in: [...idsOf(p.equipment), ...(p.circuits?.updates ?? []).map((c) => c.equipmentId), ...recordEquipment] } },
      select: { substationId: true },
    }),
    tx.link.findMany({ where: { id: { in: idsOf(p.links) } }, select: { substationId: true } }),
    tx.fiberLine.findMany({
      where: { id: { in: [...idsOf(p.fiberLines), ...(p.cores?.updates ?? []).map((c) => c.lineId), ...(p.coreMeasurements?.creates ?? []).map((c) => c.lineId)] } },
      select: { aSubstationId: true, bSubstationId: true },
    }),
    tx.coreMeasurement.findMany({ where: { id: { in: idsOf(p.coreMeasurements) } }, select: { core: { select: { line: { select: { aSubstationId: true, bSubstationId: true } } } } } }),
  ]);
  for (const r of [...floors, ...racks, ...equipment, ...links]) add(r.substationId);
  for (const l of lines) { add(l.aSubstationId); add(l.bSubstationId); }
  for (const r of lineIdsFromRows) { add(r.core.line.aSubstationId); add(r.core.line.bSubstationId); }
  /* 기록·사진 고치기·지우기는 설비를 거쳐 국을 안다 — 같은 설비의 국이 이미 위에서 잡혔다. */
  return [...ids].sort();
}

/** 국 id 정렬 순서로 잠근다 — 두 커밋이 같은 두 국을 반대 순서로 잡으면 교착이 난다. */
export async function lockSubstations(tx: Tx, ids: readonly string[]): Promise<void> {
  if (ids.length === 0) return;
  const found = await tx.substation.count({ where: { id: { in: [...ids] } } });
  if (found !== ids.length) throw new HttpError(404, 'NOT_FOUND', '변전소를 찾을 수 없습니다');
  for (const id of ids) await tx.$executeRaw`SELECT pg_advisory_xact_lock(hashtext(${id}))`;
}
```

```ts
import type { LinkEndRef, ModelState, Side } from '@twin/core';
import { Prisma } from '../../generated/next-client/index.js';

type Tx = Prisma.TransactionClient;

type EndRow = {
  end: string; equipmentId: string | null; label: string | null;
  circuitEquipmentId: string | null; circuitNo: number | null;
  coreLineId: string | null; coreNo: number | null; coreSide: string | null;
};

/** DB 의 끝 행 → core 의 끝 참조. CHECK 제약이 「정확히 하나」를 보장한다. */
export function endRefOf(e: EndRow): LinkEndRef {
  if (e.equipmentId) return { kind: 'equipment', equipmentId: e.equipmentId, label: e.label };
  if (e.circuitEquipmentId && e.circuitNo !== null) return { kind: 'circuit', equipmentId: e.circuitEquipmentId, no: e.circuitNo };
  return { kind: 'core', lineId: e.coreLineId!, no: e.coreNo!, side: e.coreSide as Side };
}

/**
 * 건드린 국들의 **최종 상태** — `validateState` 의 입력.
 *
 * 국 안의 랙·설비·연결은 전부, 광선로는 그 국에 닿은 것 전부. 광선로의 다른 끝 단자 설비가
 * 건드리지 않은 국에 있으면 그 설비 행도 싣는다 — 안 실으면 「없는 설비」로 잘못 판정된다.
 */
export async function loadState(tx: Tx, substationIds: readonly string[]): Promise<ModelState> {
  const subs = [...substationIds];
  const [racks, equipment, links, fiberLines, cableTypes] = await Promise.all([
    tx.rack.findMany({ where: { substationId: { in: subs } }, select: { id: true, substationId: true, name: true } }),
    tx.equipment.findMany({ where: { substationId: { in: subs } }, select: { id: true, substationId: true, rackId: true, name: true, circuitCount: true } }),
    tx.link.findMany({ where: { substationId: { in: subs } }, include: { ends: true } }),
    tx.fiberLine.findMany({
      where: { OR: [{ aSubstationId: { in: subs } }, { bSubstationId: { in: subs } }] },
      select: { id: true, cableTypeId: true, coreCount: true, aSubstationId: true, aEquipmentId: true, bSubstationId: true, bEquipmentId: true },
    }),
    tx.cableType.findMany({ select: { id: true, medium: true } }),
  ]);
  const known = new Set(equipment.map((e) => e.id));
  const farIds = fiberLines.flatMap((l) => [l.aEquipmentId, l.bEquipmentId]).filter((x): x is string => !!x && !known.has(x));
  const far = farIds.length
    ? await tx.equipment.findMany({ where: { id: { in: farIds } }, select: { id: true, substationId: true, rackId: true, name: true, circuitCount: true } })
    : [];
  /* 먼 설비의 랙도 싣는다 — 안 실으면 「랙이 없는 설비」로 잘못 판정된다. */
  const farRacks = far.length
    ? await tx.rack.findMany({ where: { id: { in: far.map((e) => e.rackId) } }, select: { id: true, substationId: true, name: true } })
    : [];
  return {
    racks: [...racks, ...farRacks],
    /* 다른 국의 설비는 이름 겹침 판정에 섞이지 않는다 — 국이 다르면 이름이 같아도 된다. */
    equipment: [...equipment, ...far],
    fiberLines,
    links: links.map((l) => {
      const a = l.ends.find((e) => e.end === 'A')!;
      const b = l.ends.find((e) => e.end === 'B')!;
      return { id: l.id, substationId: l.substationId, cableTypeId: l.cableTypeId, a: endRefOf(a), b: endRefOf(b) };
    }),
    cableTypes,
  };
}
```

```ts
const dateOrNull = (d: string | null | undefined) => (d === undefined ? undefined : d === null ? null : new Date(`${d}T00:00:00.000Z`));

/** undefined 인 칸은 빼고 넘긴다 — 「안 보냄」과 「비움(null)」을 가른다. */
function defined<T extends object>(o: T): Partial<T> {
  return Object.fromEntries(Object.entries(o).filter(([, v]) => v !== undefined)) as Partial<T>;
}

/** 지우기 — 설비(그 사진 파일 경로를 모은다) → (랙·층은 고치기·만들기 뒤에) */
export async function deleteEquipment(tx: Tx, p: Ops, orphaned: string[]): Promise<void> {
  const ids = p.equipment?.deletes ?? [];
  if (ids.length === 0) return;
  for (const ph of await tx.equipmentPhoto.findMany({ where: { equipmentId: { in: ids } }, select: { filePath: true } })) {
    orphaned.push(ph.filePath);
  }
  const del = await tx.equipment.deleteMany({ where: { id: { in: ids } } });
  if (del.count !== ids.length) throw new HttpError(422, 'INVALID_TARGET', '지울 설비 중 없는 것이 있습니다');

export async function writeFloorsRacksEquipment(tx: Tx, p: Ops): Promise<void> {
  for (const f of p.floors?.creates ?? []) await tx.floor.create({ data: f });
  for (const u of p.floors?.updates ?? []) {
    await tx.floor.update({ where: { id: u.id }, data: defined({ ...u.patch, backgroundDrawing: u.patch.backgroundDrawing as Prisma.InputJsonValue | undefined }) });
  }
  for (const r of p.racks?.creates ?? []) await tx.rack.create({ data: r });
  for (const u of p.racks?.updates ?? []) await tx.rack.update({ where: { id: u.id }, data: defined(u.patch) });

  /* 고치기 먼저 — 설비를 다른 랙으로 옮기고 옛 랙을 지우는 커밋이 흔하다. */
  for (const u of p.equipment?.updates ?? []) {
    const { circuitCount, installDate, ...rest } = u.patch;
    await tx.equipment.update({ where: { id: u.id }, data: defined({ ...rest, installDate: dateOrNull(installDate) }) });
    if (circuitCount !== undefined) await syncCircuits(tx, u.id, circuitCount);
  }
  for (const c of p.equipment?.creates ?? []) {
    const { installDate, ...rest } = c;
    await tx.equipment.create({ data: defined({ ...rest, installDate: dateOrNull(installDate) }) as Prisma.EquipmentUncheckedCreateInput });
    await syncCircuits(tx, c.id, c.circuitCount ?? 0);
  }

  for (const id of p.racks?.deletes ?? []) await tx.rack.delete({ where: { id } });
  for (const id of p.floors?.deletes ?? []) await tx.floor.delete({ where: { id } });
}

/**
 * 회로 행을 회로 수에 맞춘다(`rowsForCount`). 잘려 나갈 회로에 연결이 있으면 거부 —
 * FK 에 맡기면 「무엇이 막았는지」를 말할 수 없다.
 */
async function syncCircuits(tx: Tx, equipmentId: string, count: number): Promise<void> {
  const existing = (await tx.circuit.findMany({ where: { equipmentId }, select: { no: true } })).map((c) => c.no);
  const { create, remove } = rowsForCount(existing, count);
  if (remove.length > 0) {
    const used = await tx.linkEnd.count({ where: { circuitEquipmentId: equipmentId, circuitNo: { in: remove } } });
    if (used > 0) throw new HttpError(422, 'ROWS_IN_USE', `연결이 남은 회로 ${used}개를 잘라낼 수 없습니다 — 연결을 먼저 지우세요`);
    await tx.circuit.deleteMany({ where: { equipmentId, no: { in: remove } } });
  }
  if (create.length > 0) await tx.circuit.createMany({ data: create.map((no) => ({ equipmentId, no })) });
}

export async function writeCircuits(tx: Tx, p: Ops): Promise<void> {
  for (const u of p.circuits?.updates ?? []) {
    try {
      await tx.circuit.update({ where: { equipmentId_no: { equipmentId: u.equipmentId, no: u.no } }, data: defined(u.patch) });
    } catch {
      throw new HttpError(422, 'INVALID_TARGET', `없는 회로입니다: ${circuitKey(u.equipmentId, u.no)}`);
    }
  }
}
```

```ts
function endData(end: 'A' | 'B', e: LinkEndInput) {
  switch (e.kind) {
    case 'equipment': return { end, equipmentId: e.equipmentId, label: e.label ?? null };
    case 'circuit': return { end, circuitEquipmentId: e.equipmentId, circuitNo: e.no };

/** 지우기 단계 — 연결 → 측정 → 광선로. 연결이 먼저여야 그 끝이 가리키던 것을 지울 수 있다. */
export async function applyFiberDeletes(tx: Tx, p: CommitPayload): Promise<void> {

  if (linkIds.length > 0) await tx.link.deleteMany({ where: { id: { in: linkIds } } });

/** 쓰기 단계 — (광선로·코어·측정은 Task 8) → 연결. 연결이 마지막이어야 같은 커밋의 회로·코어를 가리킬 수 있다. */
export async function applyFiberWrites(tx: Tx, p: CommitPayload): Promise<void> {
  for (const u of p.links?.updates ?? []) {
    const { aLabel, bLabel, pathPoints, ...rest } = u.patch;
    await tx.link.update({
      where: { id: u.id },
      data: Object.fromEntries(Object.entries({ ...rest, pathPoints }).filter(([, v]) => v !== undefined)),
    });
    for (const [end, label] of [['A', aLabel], ['B', bLabel]] as const) {
      if (label === undefined) continue;
      /* 표기는 설비 끝에만 — 다른 끝에 적으면 CHECK 가 거부한다(→ 422). */
      await tx.linkEnd.update({ where: { linkId_end: { linkId: u.id, end } }, data: { label } });
    }
  }
  for (const c of p.links?.creates ?? []) {
    const { a, b, pathPoints, ...rest } = c;
    await tx.link.create({
      data: { ...rest, pathPoints: pathPoints ?? [], ends: { create: [endData('A', a), endData('B', b)] } },
    });
  }
}
```

```ts
import { circuitKey, coreKey, validateState } from '@twin/core';
import { Prisma } from '../../generated/next-client/index.js';
import { isPrismaError, nextDb } from '../db.js';
import { HttpError } from '../errors.js';
import { removePhotoFiles } from '../photoFiles.js';
import { deleteEquipment, writeCircuits, writeFloorsRacksEquipment, writeRecords } from './applyAssets.js';
import { applyFiberDeletes, applyFiberWrites } from './applyFiber.js';
import type { CommitPayload } from './schema.js';
import { lockSubstations, touchedSubstations } from './scope.js';
import { loadState } from './state.js';

type Tx = Prisma.TransactionClient;
export interface Actor { userId: string; username: string }

/**
 * 변경안 하나를 **원자적으로** 옮긴다 — 여러 국에 걸쳐도 한 트랜잭션.
 *
 * 순서: 잠금 → 기준 버전 검사 → 지우기(연결·측정·광선로·설비) → 쓰기(층·랙·설비·회로 →
 * 광선로·코어·측정 → 연결 → 기록) → **최종 상태 검증** → 변경 이력.
 * 검증은 다 적용한 뒤 한 번 한다: 중간 상태를 물으면 맞바꾸기 같은 정상 편집이 걸린다.
 */
export async function commitChanges(
  payload: CommitPayload,
  actor: Actor,
  photoFiles: ReadonlyMap<string, string> = new Map(),
): Promise<{ committedAt: string; changeLogId: string }> {
  const orphaned: string[] = [];
  try {
    const result = await nextDb.$transaction(async (tx) => {
      const subs = await touchedSubstations(tx, payload);
      await lockSubstations(tx, subs);
      await checkVersions(tx, payload);

      await applyFiberDeletes(tx, payload);
      await deleteEquipment(tx, payload, orphaned);
      await writeFloorsRacksEquipment(tx, payload);
      await writeCircuits(tx, payload);
      await applyFiberWrites(tx, payload);
      await writeRecords(tx, payload, photoFiles, orphaned);

      const issues = validateState(await loadState(tx, subs));
      if (issues.length > 0) throw new HttpError(422, 'INVALID_STATE', issues[0]!.message, issues);

      const { baseVersions: _bv, ...ops } = payload;
      const log = await tx.changeLog.create({
        data: { userId: actor.userId, username: actor.username, summary: { substations: subs, ops: summarize(ops) } as Prisma.InputJsonValue },
      });
      return { committedAt: new Date().toISOString(), changeLogId: log.id };
    }, { timeout: 60_000 });
    await removePhotoFiles(orphaned);
    return result;
  } catch (e) {
    throw asCommitError(e);
  }
}

/** 변경 이력의 한 줄 — 무엇을(엔티티·키) 어떻게(만들기·고치기·지우기) 무엇으로(본문). */
function summarize(ops: Omit<CommitPayload, 'baseVersions'>): { entity: string; op: string; key: string; body?: unknown }[] {
  const out: { entity: string; op: string; key: string; body?: unknown }[] = [];
  const crud = (entity: string, o?: { creates?: { id: string }[]; updates?: { id: string; patch: unknown }[]; deletes?: string[] }) => {
    for (const c of o?.creates ?? []) out.push({ entity, op: 'create', key: c.id, body: c });
    for (const u of o?.updates ?? []) out.push({ entity, op: 'update', key: u.id, body: u.patch });
    for (const d of o?.deletes ?? []) out.push({ entity, op: 'delete', key: d });
  };
  crud('floor', ops.floors); crud('rack', ops.racks); crud('equipment', ops.equipment);
  crud('fiberLine', ops.fiberLines); crud('coreMeasurement', ops.coreMeasurements); crud('link', ops.links);
  crud('maintenance', ops.records?.maintenance); crud('inspection', ops.records?.inspections); crud('photo', ops.records?.photos);
  for (const u of ops.circuits?.updates ?? []) out.push({ entity: 'circuit', op: 'update', key: circuitKey(u.equipmentId, u.no), body: u.patch });
  for (const u of ops.cores?.updates ?? []) out.push({ entity: 'core', op: 'update', key: coreKey(u.lineId, u.no), body: u.patch });
  return out;
}

/**
 * 기준 버전 — 고치거나 지우는 행마다 「읽었을 때의 updatedAt」과 지금이 같아야 한다.
 * 키: uuid 행은 id, 회로·코어는 자연 키(`circuitKey`·`coreKey`). 기준을 안 보낸 행도 충돌로 본다.
 */
async function checkVersions(tx: Tx, p: CommitPayload): Promise<void> {
  const base = p.baseVersions ?? {};
  const idsOf = (o?: { updates?: { id: string }[]; deletes?: string[] }) => [...(o?.updates ?? []).map((u) => u.id), ...(o?.deletes ?? [])];
  const pick = { id: true, updatedAt: true } as const;
  const [floors, racks, equipment, lines, measurements, links, circuits, cores] = await Promise.all([
    tx.floor.findMany({ where: { id: { in: idsOf(p.floors) } }, select: pick }),
    tx.rack.findMany({ where: { id: { in: idsOf(p.racks) } }, select: pick }),
    tx.equipment.findMany({ where: { id: { in: idsOf(p.equipment) } }, select: pick }),
    tx.fiberLine.findMany({ where: { id: { in: idsOf(p.fiberLines) } }, select: pick }),
    tx.coreMeasurement.findMany({ where: { id: { in: idsOf(p.coreMeasurements) } }, select: pick }),
    tx.link.findMany({ where: { id: { in: idsOf(p.links) } }, select: pick }),
    Promise.all((p.circuits?.updates ?? []).map((c) =>
      tx.circuit.findUnique({ where: { equipmentId_no: { equipmentId: c.equipmentId, no: c.no } }, select: { updatedAt: true } })
        .then((r) => ({ key: circuitKey(c.equipmentId, c.no), at: r?.updatedAt ?? null })))),
    Promise.all((p.cores?.updates ?? []).map((c) =>
      tx.core.findUnique({ where: { lineId_no: { lineId: c.lineId, no: c.no } }, select: { updatedAt: true } })
        .then((r) => ({ key: coreKey(c.lineId, c.no), at: r?.updatedAt ?? null })))),
  ]);
  const server = new Map<string, string | null>([
    ...[...floors, ...racks, ...equipment, ...lines, ...measurements, ...links].map((r) => [r.id, r.updatedAt.toISOString()] as const),
    ...[...circuits, ...cores].map((r) => [r.key, r.at?.toISOString() ?? null] as const),
  ]);
  const wanted = [
    ...idsOf(p.floors), ...idsOf(p.racks), ...idsOf(p.equipment), ...idsOf(p.fiberLines), ...idsOf(p.coreMeasurements), ...idsOf(p.links),
    ...circuits.map((c) => c.key), ...cores.map((c) => c.key),
  ];
  type Conflict = { key: string; reason: 'deleted' } | { key: string; reason: 'modified'; serverUpdatedAt: string };
  /* 회로·코어 행이 **아직 없으면** 묻지 않는다 — 같은 커밋에서 만든 설비·선로이거나 개수를 늘려
     생길 행이다(기준이 있을 수 없다). 정말 없는 행이면 적용 단계가 422 INVALID_TARGET 으로 막는다. */
  const notYet = new Set([...circuits, ...cores].filter((r) => r.at === null).map((r) => r.key));
  const conflicts: Conflict[] = [...new Set(wanted)].filter((key) => !notYet.has(key)).flatMap((key): Conflict[] => {
    const now = server.get(key) ?? null;
    if (now === null) return [{ key, reason: 'deleted' }];
    if (base[key] !== now) return [{ key, reason: 'modified', serverUpdatedAt: now }];
    return [];
  });
  if (conflicts.length > 0) throw new HttpError(409, 'CONFLICT', '다른 변경과 충돌했습니다. 새로고침 후 다시 시도하세요.', conflicts);
}

/** DB 가 튕긴 것을 사람 말로 — 유일 위반은 이름, FK 위반은 남은 참조, CHECK 위반은 끝 모양. */
function asCommitError(e: unknown): unknown {
  if (e instanceof HttpError) return e;
  if (isPrismaError(e, 'P2002')) {
    const target = String((e as Prisma.PrismaClientKnownRequestError).meta?.target ?? '');
    if (target.includes('name')) return new HttpError(409, 'NAME_TAKEN', '같은 국에 같은 이름이 이미 있습니다');
    return new HttpError(422, 'INVALID_STATE', '한 회로·코어 끝에는 연결이 하나뿐입니다');
  }
  if (isPrismaError(e, 'P2003')) {
    return new HttpError(422, 'DANGLING_REFERENCE', '지우려는 것을 아직 가리키는 것이 있습니다 — 함께 지우거나 먼저 옮기세요');
  }
  if (isPrismaError(e, 'P2025')) return new HttpError(422, 'INVALID_TARGET', '고치거나 지울 대상이 없습니다');
  if (e instanceof Prisma.PrismaClientUnknownRequestError && /check constraint/i.test(e.message)) {
    return new HttpError(422, 'INVALID_STATE', '연결 끝의 모양이 맞지 않습니다');
  }
  return e;
}
```

```ts
/**
 * 저장 — 변경안 하나를 통째로 서버에 옮기는 길. **국을 가리지 않는다**(변경안은 공사 단위다).

 * 나머지 칸에 사진이 실려 온다(칸 이름 = 사진 id). 파일은 쓰고 → 커밋하고 → 튕기면 방금 쓴
 * 것만 지운다.
 */
import { Router } from 'express';
import { adminOnly, authenticate } from './auth.middleware.js';
import { commitPayloadSchema } from './commit/schema.js';
import { commitChanges } from './commit/service.js';
import { HttpError } from './errors.js';
import { asHttpError, photoUpload, removePhotoFiles, writePhotoFile } from './photoFiles.js';

export const commitRouter = Router();
commitRouter.use(authenticate);

function readPayload(body: unknown): unknown {
  if (body && typeof body === 'object' && typeof (body as { payload?: unknown }).payload === 'string') {
    try {
      return JSON.parse((body as { payload: string }).payload);
    } catch {
      throw new HttpError(400, 'INVALID_PAYLOAD', '저장 내용을 읽을 수 없습니다');
    }
  }
  return body;
}

commitRouter.put('/commit', adminOnly, (req, res, next) => {
  photoUpload.any()(req, res, (err: unknown) => {
    if (err) {
      next(asHttpError(err));
      return;
    }
    void (async () => {
      const written: string[] = [];
      try {
        const payload = commitPayloadSchema.parse(readPayload(req.body));
        const photoFiles = new Map<string, string>();
        for (const file of (req.files as Express.Multer.File[] | undefined) ?? []) {
          photoFiles.set(file.fieldname, await writePhotoFile(file));
          written.push(photoFiles.get(file.fieldname)!);
        }
        res.json(await commitChanges(payload, { userId: req.user!.userId, username: req.user!.username }, photoFiles));
      } catch (e) {
        await removePhotoFiles(written);
        next(e);
      }
    })();
  });
});
```

```ts
/** 지우기 단계 — 연결 → 측정 → 광선로. 연결이 먼저여야 그 끝이 가리키던 것을 지울 수 있다. */
export async function applyFiberDeletes(tx: Tx, p: CommitPayload): Promise<void> {
  const linkIds = p.links?.deletes ?? [];
  if (linkIds.length > 0) await tx.link.deleteMany({ where: { id: { in: linkIds } } });
  const mIds = p.coreMeasurements?.deletes ?? [];
  if (mIds.length > 0) await tx.coreMeasurement.deleteMany({ where: { id: { in: mIds } } });
  for (const id of p.fiberLines?.deletes ?? []) await tx.fiberLine.delete({ where: { id } });
}

/** 쓰기 단계 — 광선로(코어 펼침) → 코어 → 측정 → 연결. */
export async function applyFiberWrites(tx: Tx, p: CommitPayload): Promise<void> {
  for (const c of p.fiberLines?.creates ?? []) {
    await tx.fiberLine.create({
      data: {
        id: c.id, cableTypeId: c.cableTypeId, coreCount: c.coreCount,
        name: c.name ?? null, lengthKm: c.lengthKm ?? null, segments: (c.segments ?? []) as Prisma.InputJsonValue,
        aSubstationId: c.a.substationId, aEquipmentId: c.a.equipmentId ?? null, aPanel: c.a.panel ?? null, aStartNo: c.a.startNo ?? 1,
        bSubstationId: c.b.substationId, bEquipmentId: c.b.equipmentId ?? null, bPanel: c.b.panel ?? null, bStartNo: c.b.startNo ?? 1,
      },
    });
    await syncCores(tx, c.id, c.coreCount);
  }
  for (const u of p.fiberLines?.updates ?? []) {
    const { a, b, coreCount, segments, ...rest } = u.patch;
    await tx.fiberLine.update({
      where: { id: u.id },
      data: defined({
        ...rest,
        coreCount,
        segments: segments as Prisma.InputJsonValue | undefined,
        aEquipmentId: a?.equipmentId, aPanel: a?.panel, aStartNo: a?.startNo,
        bEquipmentId: b?.equipmentId, bPanel: b?.panel, bStartNo: b?.startNo,
      }),
    });
    if (coreCount !== undefined) await syncCores(tx, u.id, coreCount);
  }
  for (const u of p.cores?.updates ?? []) {
    try {
      await tx.core.update({ where: { lineId_no: { lineId: u.lineId, no: u.no } }, data: defined(u.patch) });
    } catch {
      throw new HttpError(422, 'INVALID_TARGET', `없는 코어입니다: ${coreKey(u.lineId, u.no)}`);
    }
  }
  for (const c of p.coreMeasurements?.creates ?? []) {
    const { measuredOn, ...rest } = c;
    await tx.coreMeasurement.create({ data: { ...rest, measuredOn: dateOrNull(measuredOn) ?? null } });
  }
  for (const u of p.coreMeasurements?.updates ?? []) {
    const { measuredOn, ...rest } = u.patch;
    await tx.coreMeasurement.update({ where: { id: u.id }, data: defined({ ...rest, measuredOn: dateOrNull(measuredOn) }) });
  }

  // ── 연결 (Task 7 에서 쓴 그대로) ──
  for (const u of p.links?.updates ?? []) {
    const { aLabel, bLabel, pathPoints, ...rest } = u.patch;
    await tx.link.update({ where: { id: u.id }, data: defined({ ...rest, pathPoints }) });
    for (const [end, label] of [['A', aLabel], ['B', bLabel]] as const) {
      if (label === undefined) continue;
      await tx.linkEnd.update({ where: { linkId_end: { linkId: u.id, end } }, data: { label } });
    }
  }
  for (const c of p.links?.creates ?? []) {
    const { a, b, pathPoints, ...rest } = c;
    await tx.link.create({ data: { ...rest, pathPoints: pathPoints ?? [], ends: { create: [endData('A', a), endData('B', b)] } } });
  }
}

/**
 * 코어 행을 코어 수에 맞춘다. 잘려 나갈 코어에 연결이나 측정이 있으면 거부 — 측정은 FK 가
 * Cascade 라 그냥 두면 말없이 사라진다(OTDR 기록은 다시 잴 수 없다).
 */
async function syncCores(tx: Tx, lineId: string, count: number): Promise<void> {
  const existing = (await tx.core.findMany({ where: { lineId }, select: { no: true } })).map((c) => c.no);
  const { create, remove } = rowsForCount(existing, count);
  if (remove.length > 0) {
    const linked = await tx.linkEnd.count({ where: { coreLineId: lineId, coreNo: { in: remove } } });
    const measured = await tx.coreMeasurement.count({ where: { lineId, coreNo: { in: remove } } });
    if (linked + measured > 0) {
      throw new HttpError(422, 'ROWS_IN_USE', `연결 ${linked}건·측정 ${measured}건이 남은 코어를 잘라낼 수 없습니다`);
    }
    await tx.core.deleteMany({ where: { lineId, no: { in: remove } } });
  }
  if (create.length > 0) await tx.core.createMany({ data: create.map((no) => ({ lineId, no })) });
}
```

```ts
import { randomUUID } from 'node:crypto';
import { SEED_PICKS, type StationInventory } from '@twin/core';
import { commitChanges } from '../v2/commit/service.js';
import type { CommitPayload } from '../v2/commit/schema.js';

import { OPGW, STATIONS, seatedPlates, type StationKey } from './jikhalGangwon.js';
import { PLATE_LINES, type PlateLine } from './jikhalGangwonLines.js';

const FLOOR = '3층';

export interface JikhalInput {
  substationIds: Record<StationKey, string>;
  rackTypeIds: Record<string, string>;
  equipmentTypeIds: Record<string, string>;
  cableTypeIds: Record<string, string>;
  newId: () => string;
  inventory?: Record<string, StationInventory>;
}

type Creates<K extends keyof CommitPayload> = NonNullable<NonNullable<CommitPayload[K]> extends { creates?: infer C } ? C : never>;

function must(map: Record<string, string>, key: string, what: string): string {
  const id = map[key];
  if (!id) throw new Error(`${what} 「${key}」 이 마스터에 없습니다`);
  return id;
}

/** 한 판(국·선번장 판 번호)의 측정 — 잰 코어만. 날짜가 없으면 null(언제 쟀는지 모른다). */
function measurementsOf(line: PlateLine | undefined, lineId: string, side: 'A' | 'B', newId: () => string): Creates<'coreMeasurements'> {
  if (!line) return [];
  return line.cores.flatMap(([loss1310, dist1310, loss1550, dist1550], i) =>
    [loss1310, dist1310, loss1550, dist1550].every((v) => v == null)
      ? []
      : [{ id: newId(), lineId, coreNo: i + 1, side, measuredOn: line.measuredAt, loss1310, dist1310, loss1550, dist1550 }]);
}

export function buildJikhalPayload(input: JikhalInput): CommitPayload {
  const { substationIds, newId } = input;
  const floors: Creates<'floors'> = [];
  const racks: Creates<'racks'> = [];
  const equipment: Creates<'equipment'> = [];
  const lines: Creates<'fiberLines'> = [];
  const measurements: Creates<'coreMeasurements'> = [];
  /** 국 → OFD 설비 id. */
  const ofdOf = new Map<StationKey, string>();
  /** (국, 선번장 판 번호) → { 선로 id, 끝 } — 국 설비의 점퍼가 코어를 가리킬 때 쓴다. */
  const plateEnd = new Map<string, { lineId: string; side: 'A' | 'B' }>();

  for (const { key } of STATIONS) {
    const sub = substationIds[key];
    const floorId = newId();
    floors.push({ id: floorId, substationId: sub, name: FLOOR, sortOrder: 0 });
    const rackId = newId();
    racks.push({ id: rackId, substationId: sub, name: 'OFD', rackTypeId: must(input.rackTypeIds, SEED_PICKS.ofdRackType, '랙 종류'), floorId, x: 40, y: 40, width: 70, height: 70, facing: '아래' });
    const ofdId = newId();
    equipment.push({ id: ofdId, substationId: sub, rackId, name: 'OFD', typeId: must(input.equipmentTypeIds, SEED_PICKS.ofdEquipmentType, '설비 종류'), panelCount: Math.max(8, seatedPlates(key).length) });
    ofdOf.set(key, ofdId);
  }

  const opgw = must(input.cableTypeIds, SEED_PICKS.opgwCableType, '케이블 종류');
  for (const seg of OPGW) {
    const aPlates = seatedPlates(seg.a);
    const bPlates = seatedPlates(seg.b);
    const aIdx = aPlates.findIndex((p) => p.slot === seg.aSlot);
    const bIdx = bPlates.findIndex((p) => p.slot === seg.bSlot);
    const aLine = PLATE_LINES[seg.a]?.[seg.aSlot];
    const bLine = PLATE_LINES[seg.b]?.[seg.bSlot];
    const lineId = newId();
    /* 선로명은 먼저 적힌 쪽, 긍장은 적힌 쪽 — 옛 시드(opgwSpec)와 같은 규칙. */
    lines.push({
      id: lineId, cableTypeId: opgw, coreCount: aPlates[aIdx]!.cores,
      name: aLine?.line ?? bLine?.line ?? null, lengthKm: aLine?.lengthKm ?? bLine?.lengthKm ?? null,
      a: { substationId: substationIds[seg.a], equipmentId: ofdOf.get(seg.a)!, panel: aIdx + 1 },
      b: { substationId: substationIds[seg.b], equipmentId: ofdOf.get(seg.b)!, panel: bIdx + 1 },
    });
    measurements.push(...measurementsOf(aLine, lineId, 'A', newId), ...measurementsOf(bLine, lineId, 'B', newId));
    plateEnd.set(`${seg.a}#${seg.aSlot}`, { lineId, side: 'A' });
    plateEnd.set(`${seg.b}#${seg.bSlot}`, { lineId, side: 'B' });
  }

  const payload: CommitPayload = {
    floors: { creates: floors },
    racks: { creates: racks },
    equipment: { creates: equipment },
    fiberLines: { creates: lines },
    coreMeasurements: { creates: measurements },
  };
  if (input.inventory) addInventory(payload, input, plateEnd);
  return payload;
}

/** 국 설비(랙·설비·회로·연결) — Task 11 에서 채운다. */
function addInventory(_payload: CommitPayload, _input: JikhalInput, _plateEnd: Map<string, { lineId: string; side: 'A' | 'B' }>): void {}

/** 국이 하나도 없을 때만 — 재시작마다 도는 시드가 운영 데이터를 건드리면 안 된다. */
export async function seedJikhal(inventory?: Record<string, StationInventory>): Promise<void> {
  if ((await nextDb.substation.count()) > 0) {
    console.log('[seed:jikhal] 변전소가 이미 있음 — skip');
    return;
  }
  const branch = await nextDb.branch.findFirst({ where: { name: '직할', headquarters: { name: '강원본부' } } });
  if (!branch) {
    console.log('[seed:jikhal] 강원본부 직할이 없음 — skip');
    return;
  }
  const substationIds = {} as Record<StationKey, string>;
  for (const [i, s] of STATIONS.entries()) {
    substationIds[s.key] = (await nextDb.substation.create({ data: { branchId: branch.id, name: s.name, sortOrder: i } })).id;
  }
  const byKey = (rows: { key: string; id: string }[]) => Object.fromEntries(rows.map((r) => [r.key, r.id]));
  const payload = buildJikhalPayload({
    substationIds,
    rackTypeIds: byKey(await nextDb.rackType.findMany({ select: { key: true, id: true } })),
    equipmentTypeIds: byKey(await nextDb.equipmentType.findMany({ select: { key: true, id: true } })),
    cableTypeIds: byKey(await nextDb.cableType.findMany({ select: { key: true, id: true } })),
    newId: randomUUID,
    inventory,
  });
  await commitChanges(payload, { userId: 'seed', username: 'seed' });
  console.log(`[seed:jikhal] 국 ${STATIONS.length}, 광선로 ${payload.fiberLines?.creates?.length ?? 0}, 측정 ${payload.coreMeasurements?.creates?.length ?? 0}, `
    + `설비 ${payload.equipment?.creates?.length ?? 0}, 연결 ${payload.links?.creates?.length ?? 0}`);
}
```

```ts
    }
    for (const [itemName, x] of Object.entries(map.extra ?? {})) {
      const n = `${eq.name}${x.suffix}`;
      addName(n);
      rack.equipment.push({ name: n, type: x.type });
      resolveTable.set(`${eq.name}/${itemName}`, n);
    }
    for (const [, typeKey, name] of eq.fill ?? []) {
      const type = FILL_MAP[typeKey];
      if (!type) throw new Error(`${station}: 모르는 채움 품목 ${typeKey}`);
      addName(name);
      rack.equipment.push({ name, type });
      resolveTable.set(`${eq.name}/${name}`, name);
    }
    racks.push(rack);
  }

  const parse = (at: string) => {
    const m = /^(.+)\/(.+)\/([^/:]+):(\d+)$/.exec(at);
    if (!m) throw new Error(`${station}: 포트 주소 형식 ${at}`);
    const [, root, item, group, n] = m;
    const equipment = resolveTable.get(`${root}/${item}`);
    if (!equipment) throw new Error(`${station}: 풀 수 없는 주소 ${at}`);
    return { root: root!, item: item!, group: group!, n: Number(n), equipment };
  };
  const circuit = (equipment: string, key: string, label: string | null, current: 'AC' | 'DC' | null, capacity: string | null): InvEnd => {
    const keys = circuitNo.get(equipment) ?? new Map<string, number>();
    circuitNo.set(equipment, keys);
    let no = keys.get(key);
    if (no === undefined) {
      no = keys.size + 1;
      keys.set(key, no);
      const list = circuitsOf.get(equipment) ?? [];
      list.push({ no, label, current, capacity });
      circuitsOf.set(equipment, list);
    }
    return { circuit: [equipment, no] };
  };
  const equipEnd = (at: string, withLabel: boolean): InvEnd => {
    const p = parse(at);
    /* 채운 장비면 그 장비가 곧 항목이라 포트만, 랙의 주 설비면 어느 부품의 포트인지까지 적는다. */
    const label = p.item === p.equipment ? `${p.group}:${p.n}` : `${p.item} ${p.group}:${p.n}`;
    return withLabel ? { equipment: p.equipment, label } : { equipment: p.equipment };
  };

  const links: InvLink[] = [];
  for (const panel of kit.panels) {
    const asmKey = kit.equipment.find((e) => e.name === panel.equip)?.assembly;
    const asm = asmByKey.get(asmKey ?? '');
    for (const [bus, branches] of Object.entries(panel.buses)) {
      const busType = asm?.items.find((i) => i.name === bus)?.typeKey ?? '';
      branches.forEach(([label, ampere, to], i) => {
        const end = circuit(panel.equip, `${bus}/${i + 1}`, label, BUS_CURRENT[busType] ?? null, ampere ? `${ampere}A` : null);
        if (to) links.push({ cable: 'F-CV', a: end, b: equipEnd(to, false) });
      });
    }
  }
  for (const [from, to] of kit.feeds) {
    const f = parse(from);
    const a: InvEnd = /OUT/.test(f.group)
      ? circuit(f.equipment, `${f.item}/${f.n}`, `${f.item} ${f.n}`, /DC/.test(f.group) ? 'DC' : 'AC', null)
      : { equipment: f.equipment };
    links.push({ cable: 'F-CV', a, b: equipEnd(to, false) });
  }
  for (const [plate, core, to] of kit.fiber?.jumpers ?? []) {
    links.push({ cable: 'FIBER-JUMPER', a: { core: [plate, core] }, b: equipEnd(to, true) });
  }
  for (const [pa, ca, pb, cb] of kit.fiber?.patches ?? []) {
    links.push({ cable: 'FIBER-JUMPER', a: { core: [pa, ca] }, b: { core: [pb, cb] } });
  }

  for (const r of racks) for (const e of r.equipment) {
    const cs = circuitsOf.get(e.name);
    if (cs) e.circuits = cs;
  }
  out[station] = { racks, links };
}

process.stdout.write(JSON.stringify(out, null, 2));
```

`backend/src/seed/jikhal.ts` 의 빈 `addInventory` 를 바꾼다(그리고 `InvEnd` 를 import 에 더한다):

```ts
import { SEED_PICKS, type InvEnd, type StationInventory } from '@twin/core';
// …

/**
 * 국 설비 — 랙·설비(+회로 수와 회로 값)·연결. 이름으로 적힌 끝을 id 로 푼다.
 * 점퍼가 가리키는 판이 세운 광선로가 아니면(대국이 직할 밖) 그 점퍼는 버린다 — 반대편이 없다.
 */
function addInventory(payload: CommitPayload, input: JikhalInput, plateEnd: Map<string, { lineId: string; side: 'A' | 'B' }>): void {
  const racks = payload.racks!.creates!;
  const equipment = payload.equipment!.creates!;
  const circuits: NonNullable<NonNullable<CommitPayload['circuits']>['updates']> = [];
  const links: Creates<'links'> = [];
  let dropped = 0;

  for (const { key } of STATIONS) {
    const inv = input.inventory![key];
    if (!inv) continue;
    const sub = input.substationIds[key];
    const eqId = new Map<string, string>();
    for (const r of inv.racks) {
      const rackId = input.newId();
      racks.push({ id: rackId, substationId: sub, name: r.name, rackTypeId: must(input.rackTypeIds, r.rackType, '랙 종류') });
      for (const e of r.equipment) {
        const id = input.newId();
        eqId.set(e.name, id);
        equipment.push({ id, substationId: sub, rackId, name: e.name, typeId: must(input.equipmentTypeIds, e.type, '설비 종류'), circuitCount: e.circuits?.length ?? 0 });
        for (const c of e.circuits ?? []) {
          circuits.push({ equipmentId: id, no: c.no, patch: { label: c.label, current: c.current, capacity: c.capacity } });
        }
      }
    }
    const end = (x: InvEnd): NonNullable<Creates<'links'>[number]['a']> | null => {
      if ('equipment' in x) return { kind: 'equipment', equipmentId: eqId.get(x.equipment)!, label: x.label ?? null };
      if ('circuit' in x) return { kind: 'circuit', equipmentId: eqId.get(x.circuit[0])!, no: x.circuit[1] };
      const at = plateEnd.get(`${key}#${x.core[0]}`);
      return at ? { kind: 'core', lineId: at.lineId, no: x.core[1], side: at.side } : null;
    };
    for (const l of inv.links) {
      const a = end(l.a);
      const b = end(l.b);
      if (!a || !b) { dropped++; continue; }
      links.push({ id: input.newId(), substationId: sub, cableTypeId: must(input.cableTypeIds, l.cable, '케이블 종류'), a, b });
    }
  }
  payload.circuits = { updates: circuits };
  payload.links = { creates: links };
  if (dropped > 0) console.log(`[seed:jikhal] 직할 밖 판을 가리키는 점퍼 ${dropped}건은 버림`);
}
```
