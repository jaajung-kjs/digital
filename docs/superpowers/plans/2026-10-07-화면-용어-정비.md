# 화면 용어 정비 — 구어체를 업무 용어로 (2026-10-07)

사용자 지시: 「잇기, 이쪽 표기, 이쪽 끝 같은 구어체를 전수조사해 전부 비즈니스 용어로 바꾼다.」
범위: **화면에 보이는 모든 글자** — 프론트 JSX·문자열, core/백엔드가 화면으로 내보내는 오류·검증 문구.
코드 식별자·주석·시험 이름은 범위 밖(주석은 고치지 않는다).

## 용어집 (이것을 기준으로 바꾼다)

### 동작 (단추·메뉴·확인 창)
| 구어체 | 업무 용어 |
|---|---|
| 잇기 | 연결 (단추: 「연결」, 창 제목: 「연결 추가」) |
| 지우기 · 지운다 · 지울 | 삭제 · 삭제한다 · 삭제할 |
| 고치기 · 고친 · 고칠 · 고치지 | 수정 · 수정한 · 수정할 · 수정하지 |
| 넣기 · 넣으세요 · 넣습니다 | 입력 · 등록 (문맥: 값은 입력, 행 생성은 등록) — 「입력하세요」, 「n건을 등록합니다」 |
| 고르기 · 고르세요 · 골라 · 고른 | 선택 · 선택하세요 · 선택하여 · 선택한/선택된 |
| 올리기 · 올린 · 올리세요 · 올린이 | 업로드 · 등록 — 「업로드하세요」, 「등록 이력」, 「등록자」 |
| 놓기 · 놓인 · 놓을 | 배치 · 배치된 · 배치할 |
| 빼기 (도면에서 빼기) | 배치 해제 |
| 되돌리기 / 다시 실행 | 실행 취소 / 다시 실행 · 「변경 되돌리기」→「변경 취소」 |
| 되돌릴 수 없습니다 | 복구할 수 없습니다 |
| 잘라낼 수 없습니다 | 삭제할 수 없습니다 |
| 끌어서 자리 지정 | 드래그하여 위치 지정 |
| 펼치기 · 접기 | 그대로(표준 UI 용어) |
| 불러오는 중 · 불러오지 못했습니다 | 그대로(표준) |

### 연결·광선로의 양 끝
| 구어체 | 업무 용어 |
|---|---|
| 이쪽 끝 / 상대 끝 (광선로·코어·측정) | **자국 측 / 대국 측** — 「자국 측 · 북춘천S/S」 |
| 이쪽 끝 (연결 — 설비 상세·연결 창) | **본 설비 단자** |
| 반대쪽 끝 · 상대 (연결 창) | **상대 단자** — 검색 안내 「상대 단자 검색」 |
| 이쪽 표기 / 상대 표기 | **본 설비 단자 표기 / 상대 단자 표기** |
| 이쪽: 차단기 n (연결 목록 둘째 줄) | **단자: 차단기 n** |
| 측정 끝 | **측정 위치** (자국 측 / 대국 측) |
| 광선로 끝의 … 그 끝의 국 | 광선로 종단의 … 해당 종단 변전소 |
| 끝 (연결의 끝) | **단자** / 종단(광선로) |

### 상태·안내 문구
| 구어체 | 업무 용어 |
|---|---|
| 고른 설비가 없습니다 | 선택된 설비가 없습니다 |
| 찾는 국이 없습니다 · 찾는 끝이 없습니다 | 검색 결과가 없습니다 |
| '<q>' 와 맞는 … | '<q>'에 해당하는 …이(가) 없습니다 |
| 조건과 맞는 … | 조건에 해당하는 … |
| 이 국에 닿은 광선로 | 이 변전소에 수용된 광선로 |
| 잰 코어 | 측정한 코어 |
| … 꼴로 넣으세요 | … 형식으로 입력하세요 |
| 고칠 칸이 있습니다 | 입력 오류가 있습니다 |
| 숫자만 넣으세요 | 숫자만 입력하세요 |
| 통째로 바꿔 올리지 | 일괄 교체하지 |
| 담겨 / 들어 있어 | 포함되어 |
| 국 (문장 속) | 변전소 (단 「자국·대국·상대국」 열·필드명은 현장 선번장 용어라 유지) |

### 원칙
- 문장은 「~합니다/~하세요」 체로 맞춘다. 「~요」, 반말, 의성·구어 동사(잇다·걷다·들르다·놓다·고르다·넣다·올리다·지우다·고치다)를 쓰지 않는다.
- 같은 동작은 화면 어디서나 같은 말: 삭제·수정·등록·선택·업로드·배치·연결.
- 현장 고유 명사(선번장·자국·대국·어댑터·슬롯·차단기·실장 설비·긍장)는 유지한다.
- 공식 기준 문서 열 이름(조달청 「공사종류」 등)은 원문 그대로.

## 2차 정비 — 현장 문서 어휘로 (2026-10-07, 사용자 승인)

근거: 현장 엑셀(소형광 선번장 「설치장소·대국장소·카드·포트번호·회선 사용 내역」, OFD 선번장 「상대국명·회선수용내역·접속개소」,
분전반 「CB번호·용량A·부하명·전원케이블」, 충전기·UPS 「입력·출력」, 「접속설비」). 「본 설비」「단자 표기」「상대 단자」는 현장 문서에 없다.

| 1차 | 2차(최종) |
|---|---|
| 본 설비 단자 표기 / 단자 표기 | **포트** (예 AC IN, C1 WEST) |
| 상대 단자 표기 / 상대 표기 | **상대 포트** |
| 연결 추가 머리 「본 설비 단자: …」 / 「자국 측 코어: …」 | **기준 설비: …** / **기준 코어: …** |
| 상대 단자(고르는 목록) · 상대 단자 검색 | **접속 설비** · 접속 설비 검색 |
| 연결 목록 둘째 줄 「단자: 차단기 3 · F-CV」 | **차단기 3 · F-CV 전력케이블 · 12 m** (머리말 없음) |
| 연결 목록 묶음 「전원 공급원 / 부하」 | **입력 전원 / 부하** |
| 선번장 열 「자국 연결 / 대국 연결」 | **자국 접속 / 대국 접속** |
| 선번장 열 「용도」(코어) | **회선 내역** (상대 끝 값 툴팁 「대국 회선 내역: …」) |
| 자국 측 / 대국 측 (측정 이력·광선로 창·측정 위치) | **자국 / 대국** (「자국 · 북춘천S/S」) |
| 광선로 창 「자국 측 단자 · 단자 설비」 | **자국 · 접속 설비 · 슬롯 · 시작번호** |
| 단자 미지정 | **접속 설비 미지정** |
| 교류/직류 · 차단기 | 유지 |

「단자」라는 말은 화면에서 쓰지 않는다(가드 금지어에 「본 설비」「단자 표기」「상대 단자」 추가).
