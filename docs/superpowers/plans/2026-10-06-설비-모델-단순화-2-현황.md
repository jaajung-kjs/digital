# 설비 모델 단순화 ② 현황 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 프론트엔드를 새 모델(랙·설비·회로·광선로·연결)과 새 API(`PUT /api/v2/commit`, 국 워킹카피)에 맞게 다시 세워 앱을 다시 온전히 돌린다 — 현황(품목별 대수·랙별 표)·상세 패널(정보·회로·연결·점검·사진)·평면도(랙 배치)·잇기(국 목록에서 고르기)·품목 관리 두 화면.

**Architecture:** 새 프론트 모델 계층을 `frontend/src/v2/model/`(타입·API·훅·워킹카피 스토어·파생 셀렉터·커밋 페이로드)에 세우고, 화면을 하나씩 그 위로 옮긴 뒤, 마지막에 옛 포트·설비 품목·추적·대장 코드를 프론트와 core 에서 걷어 낸다. 워킹카피는 **공사 단위**다 — 들른 국을 base 에 더하고 오버레이 하나로 모든 국의 변경을 쌓는다(보류·복귀 없음). 판정은 core(`validateState`·`expandDeletes`·`rowsForCount`)를 그대로 쓴다.

**Tech Stack:** React 18, TypeScript, zustand(+zundo), @tanstack/react-query, axios, Tailwind(시맨틱 토큰), vitest + Testing Library, Vite. 백엔드 Express/Prisma(작은 수정 1건).

**Spec:** `docs/superpowers/specs/2026-10-06-설비-모델-단순화-design.md` (§화면, §저장). ① 계획: `docs/superpowers/plans/2026-10-06-설비-모델-단순화-1-모델-저장.md`.

## Global Constraints

- **UI 를 만들기 전에 `frontend/src/components/ui/CONVENTIONS.md` 를 먼저 읽고 그대로 따른다**(CLAUDE.md 강제 규칙): 본문 `text-sm`·라벨 `text-xs`(미만 금지), 시맨틱 색·z 토큰만, 공용 컴포넌트(`DetailCard`·`DetailRow`·`TableCard`·`Td`·`Th`·`Button`·`Input`·`Select`·`Modal`·`ViewCard`·`Tabs`·`FilterChip`·`TableSearch`·`StatusDot`·`EmptyState` 등) 재사용, 크기는 prop 으로, 행 액션은 호버, 표는 크롬 고정·본문 스크롤.
- **화면 말:** 「종류」를 쓰지 않는다(CONVENTIONS §0) — 마스터는 **설비 품목·랙 품목·케이블 품목**, 분야는 **분야**. 바닥에 서는 함체는 **랙**, 랙 안에서 세는 것은 **설비**. 「자산」 금지.
- 판정은 `@twin/core` 한 곳(`validateState`·`expandDeletes`·`rowsForCount`·어휘 `CABLE_MEDIA`·`EQUIPMENT_STATUSES`·`CORE_STATUSES`). 프론트에 같은 규칙을 다시 쓰지 않는다.
- **종류 key 로 가르는 코드 0** — 프론트에 설비·랙·케이블 품목 key 문자열 리터럴 금지(가드레일).
- 변경안은 **공사 단위**: 국을 옮겨도 오버레이를 버리지 않는다. 보류·복귀·읽기 전용 전환은 없다.
- 잇기의 끝을 고르는 곳은 **이 국의 설비·회로·코어 끝 목록**(검색) 하나다. 도면 클릭으로 잇지 않는다.
- 회로·코어는 자연 키(`circuitKey`·`coreKey`)로 가리킨다. 회로 행은 `circuitCount` 로만 생기고 없어진다.
- 저장 경로는 `PUT /api/v2/commit` 하나. 저장 뒤에는 들른 국을 모두 다시 읽어 버전을 맞춘다(서버가 새 버전을 돌려주지 않는다 — ① 결정).
- 날짜: 서버는 `installDate`·`measuredOn` 을 ISO datetime 으로 주고 `YYYY-MM-DD` 로 받는다 → 프론트가 **불러올 때 한 곳**(`model/api.ts` 의 `normalizeWorkingcopy`)에서 `YYYY-MM-DD` 로 접는다.
- 이번 단계에서 **선번장·계통 탭과 산출 내역(설계서)은 내린다** — ③·④·⑥ 에서 새로 선다.
- 개발 규칙: DB 는 이미 떠 있는 `ict-twin-postgres`(워크트리 `backend/.env` → `digital_simplify`). `docker compose build/up` 금지. 빌드 확인 `npm run build`.
- 커밋 메시지 끝: `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. **국을 옮겨 다니며 편집한 뒤 저장** — A국에서 랙을 만들고 B국으로 가서 설비를 고친 뒤 저장하면 두 국의 변경이 한 번에 저장되고, 저장 바가 두 국을 다 센다. Task 3 시험 + Task 10 브라우저 시나리오.
2. **회로 수를 늘린 직후 새 회로에 연결** — 같은 변경안 안에서 회로 4번이 화면에 나타나고 거기에 연결을 걸 수 있다(회로 행은 서버가 아직 모른다). Task 3 시험(`effectiveCircuits`)·Task 6 시험.
3. **설비 삭제 시 함께 가는 것이 화면에 보인다** — `expandDeletes` 결과(연결 삭제)가 오버레이에 들어가고 저장 페이로드에 실린다. 막힌 랙 삭제는 까닭을 띄우고 아무것도 바꾸지 않는다. Task 3·Task 5 시험.
4. **충돌(409) 후** — 충돌 대화상자가 행 키(`key`)로 무엇이 충돌했는지 이름을 보여 주고, 새로고침은 들른 국 모두를 다시 읽는다. Task 3·Task 4 시험.
5. **저장 전 검증** — 같은 국 설비 이름 겹침 같은 흠은 서버까지 가기 전에 저장 바에 흠 문구로 뜨고 저장을 막는다(`validateState`). Task 3 시험.

```ts
catalogRouter.get('/catalog', async (_req, res, next) => {
  try {
    const order = [{ sortOrder: 'asc' as const }, { name: 'asc' as const }];
    const [categories, rackTypes, equipmentTypes, cableTypes, activeStandards, rates] = await Promise.all([
      nextDb.category.findMany({ orderBy: order }),
      nextDb.rackType.findMany({ orderBy: order }),
      nextDb.equipmentType.findMany({ orderBy: order }),
      nextDb.cableType.findMany({ orderBy: order }),
      /* 적용 중인 기준정보를 카탈로그에 싣는다 — 노임은 노무유형 고르기의 어휘이자 설계서의
         단가이고, 제비율은 설계서의 요율이다. 화면마다 따로 조회하면 「어느 판을 봤나」가 갈린다. */

      /* 직종 노임은 시계열 — 코드마다 가장 최근 값이 현재 단가다. */
      nextDb.laborRate.findMany({ orderBy: [{ code: 'asc' }, { effectiveOn: 'desc' }] }),
    ]);
    const latestByCode = new Map<string, (typeof rates)[number]>();
    for (const r of rates) if (!latestByCode.has(r.code)) latestByCode.set(r.code, r);
    const latest = rates.reduce<(typeof rates)[number] | null>((acc, r) => (acc === null || r.effectiveOn > acc.effectiveOn ? r : acc), null);
    const overhead = activeStandards.find((s) => s.kind === 'overhead') ?? null;
    res.json({
      categories, rackTypes, equipmentTypes, cableTypes, media: CABLE_MEDIA,
      wageStandard: latestByCode.size > 0
        ? {
            latestDate: latest?.effectiveLabel ?? null,
            rows: [...latestByCode.values()].map((r) => ({
              code: r.code, name: r.name, sector: r.sector, wage: r.wage,
              marker: r.marker, markerNote: r.markerNote, effectiveLabel: r.effectiveLabel,
            })),
          }
        : null,
      overheadStandard: overhead ? { id: overhead.id, ...(overhead.payload as Record<string, unknown>) } : null,
    });
  } catch (e) {
    next(e);
  }
});
```

```ts
import { httpClient as api } from '../httpClient';
import type { Catalog, CatalogKind, CommitPayload, NodeEquipmentRow, Workingcopy } from './types';

/** ISO datetime → `YYYY-MM-DD`. 이미 그 꼴이거나 비었으면 그대로. */
function dateOnly(v: string | null | undefined): string | null {
  if (!v) return null;
  return v.length > 10 ? v.slice(0, 10) : v;
}

/**
 * 서버가 준 워킹카피의 날짜를 **한 번** 접는다 — 저장이 `YYYY-MM-DD` 만 받으므로,
 * 읽은 그대로 다시 보내도 맞게. 화면 어디서도 다시 자르지 않는다.
 */
export function normalizeWorkingcopy(raw: Workingcopy): Workingcopy {
  return {
    ...raw,
    equipment: raw.equipment.map((e) => ({ ...e, installDate: dateOnly(e.installDate) })),
    fiberLines: raw.fiberLines.map((l) => ({
      ...l,
      cores: l.cores.map((c) => ({ ...c, measurements: c.measurements.map((m) => ({ ...m, measuredOn: dateOnly(m.measuredOn) })) })),
    })),
  };
}

export async function fetchWorkingcopy(substationId: string): Promise<Workingcopy> {
  return normalizeWorkingcopy((await api.get(`/v2/substations/${substationId}/workingcopy`)).data);
}

/**
 * 저장 — 변경안 하나를 통째로. **국을 가리지 않는다**(공사 단위).
 * 사진 파일이 있으면 multipart: `payload` 칸에 JSON, 사진은 제 id 를 칸 이름으로.
 */
export async function putCommit(
  payload: CommitPayload,
  photoFiles: ReadonlyMap<string, File> = new Map(),
): Promise<{ committedAt: string; changeLogId: string }> {
  if (photoFiles.size === 0) return (await api.put('/v2/commit', payload)).data;
  const form = new FormData();
  form.append('payload', JSON.stringify(payload));
  for (const [photoId, file] of photoFiles) form.append(photoId, file);
  /* Content-Type 을 비워 브라우저가 multipart boundary 를 채우게 한다(인스턴스 기본이 JSON). */
  return (await api.put('/v2/commit', form, { headers: { 'Content-Type': undefined } })).data;
}
```

```ts
/** 마스터 넷의 만들기·고치기·지우기 — 끝나면 카탈로그를 다시 읽는다. */
export function useCatalogMutations() {
  const qc = useQueryClient();
  const done = { onSuccess: () => qc.invalidateQueries({ queryKey: CATALOG_KEY }) };
  return {
    create: useMutation({ mutationFn: (v: { kind: CatalogKind; body: Record<string, unknown> }) => createCatalogRow(v.kind, v.body), ...done }),

    remove: useMutation({ mutationFn: (v: { kind: CatalogKind; id: string }) => deleteCatalogRow(v.kind, v.id), ...done }),
  };
}
```

```ts
/** id 로 합친다 — 광선로처럼 두 국 응답에 같은 행이 실려도 하나로. 뒤에 온 것이 이긴다. */
function mergeById<T>(prev: T[], next: T[], keyOf: (r: T) => string): T[] {
  const m = new Map(prev.map((r) => [keyOf(r), r]));
  for (const r of next) m.set(keyOf(r), r);
  return [...m.values()];
}
const byId = (r: { id: string }) => r.id;

/** 한 국 응답을 base 에 더한다. 그 국의 국-소속 행은 응답이 정답이다(지워진 행이 남지 않게). */
function absorb(saved: Saved, wc: Workingcopy): Saved {
  const sid = wc.substation.id;
  const keep = <T extends { substationId: string }>(rows: T[]) => rows.filter((r) => r.substationId !== sid);
  const lineIds = new Set(wc.fiberLines.map((l) => l.id));
  const eqIds = new Set(wc.equipment.map((e) => e.id));
  const equipment = wc.equipment.map(({ circuits: _c, ...e }) => e);
  const fiberLines = wc.fiberLines.map(({ cores: _c, ...l }) => l);
  const cores = wc.fiberLines.flatMap((l) => l.cores.map(({ measurements: _m, ...c }) => c));
  const measurements = wc.fiberLines.flatMap((l) => l.cores.flatMap((c) => c.measurements));
  return {
    substations: { ...saved.substations, [sid]: wc.substation },
    floors: [...keep(saved.floors), ...wc.floors],
    racks: [...keep(saved.racks), ...wc.racks],
    equipment: [...keep(saved.equipment), ...equipment],
    circuits: [...saved.circuits.filter((c) => !eqIds.has(c.equipmentId)), ...wc.equipment.flatMap((e) => e.circuits)],
    links: [...keep(saved.links), ...wc.links],
    fiberLines: mergeById(saved.fiberLines, fiberLines, byId),
    cores: [...saved.cores.filter((c) => !lineIds.has(c.lineId)), ...cores],
    coreMeasurements: [...saved.coreMeasurements.filter((m) => !lineIds.has(m.lineId)), ...measurements],
    farLinks: mergeById(saved.farLinks, wc.farLinks, byId),
    refEquipment: mergeById(saved.refEquipment, wc.refEquipment, byId),
    maintenance: [...saved.maintenance.filter((r) => !eqIds.has(r.equipmentId)), ...wc.maintenanceLogs],
    inspections: [...saved.inspections.filter((r) => !eqIds.has(r.equipmentId)), ...wc.inspectionLogs],
    photos: [...saved.photos.filter((r) => !eqIds.has(r.equipmentId)), ...wc.photos],
  };
}

/** 기준 버전 — uuid 행은 id, 회로·코어는 자연 키. 저장할 때 고치거나 지우는 행의 것만 보낸다. */
function versionsOf(s: Saved): Record<string, string> {
  const v: Record<string, string> = {};
  for (const k of ROW_KINDS) for (const r of s[k] as { id: string; updatedAt: string }[]) v[r.id] = r.updatedAt;
  for (const c of s.circuits) v[circuitKey(c.equipmentId, c.no)] = c.updatedAt;
  for (const c of s.cores) v[coreKey(c.lineId, c.no)] = c.updatedAt;
  return v;
}

  /** 들른 국 — 들른 차례대로. */

  /** 읽는 중인 국(없으면 null). */

  reset: () => void;

      loaded: [],
      loading: null,
      saved: EMPTY_SAVED,
      overlays: emptyOverlays(),
      baseVersions: {},

      ensureLoaded: async (substationId) => {
        if (get().loaded.includes(substationId)) return;
        const t = workingCopyStore.temporal.getState();
        t.pause();
        set({ loading: substationId });
        try {
          const wc = await fetchWorkingcopy(substationId);
          const saved = absorb(get().saved, wc);
          set({ saved, baseVersions: versionsOf(saved), loaded: [...get().loaded.filter((x) => x !== substationId), substationId], loading: null });
        } catch (e) {
          set({ loading: null });
          useV2Notice.getState().showError(apiErrorMessage(e, '변전소를 불러오지 못했습니다'));
        } finally {
          t.resume();
        }
      },

      refresh: async () => {
        const ids = get().loaded;
        const t = workingCopyStore.temporal.getState();
        t.pause();
        try {
          let saved = EMPTY_SAVED;
          for (const id of ids) saved = absorb(saved, await fetchWorkingcopy(id));
          set({ saved, baseVersions: versionsOf(saved), overlays: emptyOverlays() });
        } finally {
          t.resume();
          t.clear();
        }
      },

      revert: () => {
        set({ overlays: emptyOverlays() });
        workingCopyStore.temporal.getState().clear();
      },

      reset: () => {
        set({ loaded: [], loading: null, saved: EMPTY_SAVED, overlays: emptyOverlays(), baseVersions: {} });
        workingCopyStore.temporal.getState().clear();
      },

      create: (kind, row) => set((s) => ({ overlays: { ...s.overlays, [kind]: stageCreate(s.overlays[kind] as Overlay<typeof row>, (row as { id: string }).id, row) } })),
      update: (kind, id, patch) => set((s) => ({ overlays: { ...s.overlays, [kind]: stageUpdate(s.overlays[kind] as Overlay<unknown>, id, patch as Partial<unknown>) } })),
      remove: (kind, id) => set((s) => ({ overlays: { ...s.overlays, [kind]: stageDelete(s.overlays[kind] as Overlay<unknown>, id) } })),
      updateCircuit: (equipmentId, no, patch) => set((s) => {
        const k = circuitKey(equipmentId, no);
        return { overlays: { ...s.overlays, circuits: { ...s.overlays.circuits, [k]: { ...s.overlays.circuits[k], ...patch } } } };
      }),
      updateCore: (lineId, no, patch) => set((s) => {
        const k = coreKey(lineId, no);
        return { overlays: { ...s.overlays, cores: { ...s.overlays.cores, [k]: { ...s.overlays.cores[k], ...patch } } } };
      }),

      dirtyCount: () => {
        const o = get().overlays;
        return ROW_KINDS.reduce((n, k) => n + overlayDirtyCount(o[k] as Overlay<unknown>), 0)
          + Object.keys(o.circuits).length + Object.keys(o.cores).length;
      },

      touchedSubstations: () => {
        const { overlays: o, saved } = get();
        const subs = new Set<string>();
        const subOfEquipment = (id: string) =>
          (o.equipment.creates[id] ?? saved.equipment.find((e) => e.id === id))?.substationId;
        const rowsOf = <K extends RowKind>(k: K): RowOf[K][] => [
          ...Object.values(o[k].creates),
          ...(saved[k] as RowOf[K][]).filter((r) => (r as { id: string }).id in o[k].updates || o[k].deletes.includes((r as { id: string }).id)),
        ] as RowOf[K][];
        for (const k of ['floors', 'racks', 'equipment', 'links'] as const) for (const r of rowsOf(k)) subs.add(r.substationId);
        for (const l of rowsOf('fiberLines')) { subs.add(l.aSubstationId); subs.add(l.bSubstationId); }
        for (const k of ['maintenance', 'inspections', 'photos'] as const) for (const r of rowsOf(k)) { const s = subOfEquipment(r.equipmentId); if (s) subs.add(s); }
        for (const key of Object.keys(o.circuits)) { const s = subOfEquipment(key.split(':')[1]!); if (s) subs.add(s); }
        const lineSubs = (lineId: string) => {
          const l = o.fiberLines.creates[lineId] ?? saved.fiberLines.find((x) => x.id === lineId);
          if (l) { subs.add(l.aSubstationId); subs.add(l.bSubstationId); }
        };
        for (const key of Object.keys(o.cores)) lineSubs(key.split(':')[1]!);
        for (const m of rowsOf('coreMeasurements')) lineSubs(m.lineId);
        return [...subs];
      },
    }),
    { partialize: (s) => ({ overlays: s.overlays }), equality: shallow, limit: 50 },
  ),
);
```

```ts
import { effectiveRows, toModelState } from './effective';

/**
 * 지우기 — **함께 가는 것까지 펼쳐서** 오버레이에 싣는다(`expandDeletes`). 막힌 것이 하나라도
 * 있으면 아무것도 바꾸지 않고 그 까닭을 돌려준다(화면이 띄운다).
 *
 * 지운 설비의 **저장 안 된** 기록·사진 만들기는 함께 걷는다. 저장된 기록·사진은 서버가 설비와
 * 함께 지운다 — 여기서 따로 지우라고 보내면 서버가 「없는 대상」으로 거절한다.
 */
export function deleteRows(req: DeleteRequest): { blocked: { id: string; reason: string }[] } {
  const s = workingCopyStore.getState();
  const plan = expandDeletes(toModelState(s), req);
  if (plan.blocked.length > 0) return { blocked: plan.blocked };
  const eqGone = new Set(plan.equipment);
  for (const id of plan.links) s.remove('links', id);
  for (const id of plan.fiberLines) s.remove('fiberLines', id);
  for (const c of plan.lineEndClears) {
    s.update('fiberLines', c.lineId, c.side === 'A' ? { aEquipmentId: null, aPanel: null } : { bEquipmentId: null, bPanel: null });
  }
  for (const k of ['maintenance', 'inspections', 'photos'] as const) {
    for (const r of effectiveRows(s, k)) if (eqGone.has(r.equipmentId) && r.id in workingCopyStore.getState().overlays[k].creates) s.remove(k, r.id);
  }
  for (const id of plan.equipment) s.remove('equipment', id);
  for (const id of plan.racks) s.remove('racks', id);
  return { blocked: [] };
}
```

```ts
  return Object.keys(out).length ? out : undefined;
}

const lineEnd = (side: 'a' | 'b', l: Record<string, unknown>, withSubstation: boolean) => {
  const end: Record<string, unknown> = {};
  if (withSubstation) end.substationId = l[`${side}SubstationId`];
  for (const [k, f] of [['equipmentId', `${side}EquipmentId`], ['panel', `${side}Panel`], ['startNo', `${side}StartNo`]] as const) {
    if (f in l) end[k] = l[f];
  }
  return end;
};

/**
 * 오버레이 → `PUT /commit` 본문. 서버 스키마(backend/src/v2/commit/schema.ts)와 칸 이름이 같다.
 * 지운 설비에 딸린 기록 고치기·지우기는 싣지 않는다(서버가 함께 지운다).
 */
export function buildCommitPayload(s: Pick<WorkingCopyState, 'saved' | 'overlays' | 'baseVersions'>): CommitPayload {
  const o = s.overlays;
  const p: Record<string, unknown> = {};
  const put = (k: string, v: unknown) => { if (v !== undefined) p[k] = v; };

  for (const k of ['floors', 'racks', 'equipment', 'coreMeasurements'] as const) {
    put(k, ops(o[k] as Overlay<RowOf[typeof k]>, (r) => pick(r, FIELDS[k].create), (patch) => pick(patch, FIELDS[k].update)));
  }
  put('fiberLines', ops(o.fiberLines,
    (l) => ({ id: l.id, ...pick(l, LINE_FIELDS), a: lineEnd('a', l as never, true), b: lineEnd('b', l as never, true) }),
    (patch) => {
      const out = pick(patch, LINE_FIELDS);
      const a = lineEnd('a', patch as never, false);
      const b = lineEnd('b', patch as never, false);
      if (Object.keys(a).length) out.a = a;
      if (Object.keys(b).length) out.b = b;
      return out;
    }));
  put('links', ops(o.links,
    (l) => ({ id: l.id, substationId: l.substationId, ...pick(l, LINK_FIELDS), a: l.a, b: l.b }),
    (patch) => {
      const out = pick(patch, LINK_FIELDS);
      /* 끝 대상은 바꾸지 않는다(① 규칙) — 설비 끝의 표기만 aLabel/bLabel 로. */
      if (patch.a?.kind === 'equipment') out.aLabel = patch.a.label ?? null;
      if (patch.b?.kind === 'equipment') out.bLabel = patch.b.label ?? null;
      return out;
    }));

  const circuits = Object.entries(o.circuits).map(([k, patch]) => {
    const [, equipmentId, no] = k.split(':');
    return { equipmentId: equipmentId!, no: Number(no), patch };
  });
  if (circuits.length) p.circuits = { updates: circuits };
  const cores = Object.entries(o.cores).map(([k, patch]) => {
    const [, lineId, no] = k.split(':');
    return { lineId: lineId!, no: Number(no), patch };
  });
  if (cores.length) p.cores = { updates: cores };

  /* 기록 — 지운 설비의 것은 뺀다. */
  const eqGone = new Set(o.equipment.deletes);
  const ownerOf = (kind: 'maintenance' | 'inspections' | 'photos', id: string) =>
    (o[kind].creates[id] ?? (s.saved[kind] as { id: string; equipmentId: string }[]).find((r) => r.id === id))?.equipmentId;
  const recordOps = (kind: 'maintenance' | 'inspections' | 'photos', createKeys: readonly string[], patchKeys: readonly string[]) => {
    const ov = o[kind] as Overlay<{ id: string; equipmentId: string }>;
    const alive = (id: string) => { const e = ownerOf(kind, id); return !e || !eqGone.has(e); };
    const creates = Object.values(ov.creates).filter((r) => alive(r.id)).map((r) => pick(r, createKeys));
    const updates = Object.entries(ov.updates).filter(([id]) => alive(id)).map(([id, patch]) => ({ id, patch: pick(patch, patchKeys) }));
    const deletes = ov.deletes.filter(alive);
    const out: Record<string, unknown> = {};
    if (creates.length) out.creates = creates;
    if (updates.length) out.updates = updates;
    if (deletes.length) out.deletes = deletes;
    return Object.keys(out).length ? out : undefined;
  };
  const records: Record<string, unknown> = {};
  const m = recordOps('maintenance', ['id', 'equipmentId', 'occurredAt', 'content', 'action'], ['occurredAt', 'content', 'action']);
  const i = recordOps('inspections', ['id', 'equipmentId', 'inspectedAt', 'content', 'result'], ['inspectedAt', 'content', 'result']);
  const ph = recordOps('photos', ['id', 'equipmentId', 'caption'], ['caption']);
  if (m) records.maintenance = m;
  if (i) records.inspections = i;
  if (ph) records.photos = ph;
  if (Object.keys(records).length) p.records = records;

  /* 기준 버전 — 고치거나 지우는, 이미 저장된 행만. */
  const bv: Record<string, string> = {};
  const want = (key: string) => { if (s.baseVersions[key]) bv[key] = s.baseVersions[key]; };
  for (const k of ['floors', 'racks', 'equipment', 'fiberLines', 'coreMeasurements', 'links', 'maintenance', 'inspections', 'photos'] as const) {
    for (const id of Object.keys(o[k].updates)) want(id);
    for (const id of o[k].deletes) want(id);
  }
  for (const c of circuits) want(circuitKey(c.equipmentId, c.no));
  for (const c of cores) want(coreKey(c.lineId, c.no));
  if (Object.keys(bv).length) p.baseVersions = bv;
  return p;
}
```

```ts
export function useCommit() {
  const qc = useQueryClient();
  const catalog = useCatalog();
  const [isCommitting, setCommitting] = useState(false);
  const [conflicts, setConflicts] = useState<Conflict[] | null>(null);
  const [error, setError] = useState<string | null>(null);
  const saved = useWorkingCopy((s) => s.saved);
  const overlays = useWorkingCopy((s) => s.overlays);
  const cableTypes = catalog.data?.cableTypes ?? [];
  const issues: ModelIssue[] = useMemo(
    () => validateState(toModelState({ saved, overlays }, cableTypes)),
    [saved, overlays, cableTypes],
  );

  const commit = useCallback(async () => {
    const s = workingCopyStore.getState();
    const count = s.dirtyCount();
    if (count === 0) return;
    if (issues.length > 0) { setError(issues[0]!.message); return; }
    setCommitting(true);
    setError(null);
    try {
      await putCommit(buildCommitPayload(s), pendingPhotoFiles());
      await s.refresh();
      await qc.invalidateQueries({ queryKey: ['v2', 'org-tree'] });
      await qc.invalidateQueries({ queryKey: NODE_EQUIPMENT_KEY });
      await qc.invalidateQueries({ queryKey: CATALOG_KEY });
      useV2Notice.getState().showSuccess(`변경 ${count}건을 저장했습니다`);
    } catch (e) {
      if (isAxiosError(e) && e.response?.status === 409 && Array.isArray(e.response.data?.details)) {
        setConflicts(e.response.data.details as Conflict[]);
      } else {
        setError(apiErrorMessage(e, '저장에 실패했습니다'));
      }
    } finally {
      setCommitting(false);
    }
  }, [qc, issues]);

  return {
    commit, isCommitting, conflicts, issues, error,
    clearConflicts: useCallback(() => setConflicts(null), []),
    clearError: useCallback(() => setError(null), []),
  };
}
```

```ts
/** 국 하나의 현황 행 — 설비만(랙은 세지 않는다). */
export function rowsFromWorkingCopy(s: Pick<WorkingCopyState, 'saved' | 'overlays'>, substationId: string, catalog: Pick<Catalog, 'categories' | 'equipmentTypes'>): StatusRow[] {
  const racks = new Map(bySubstation(effectiveRows(s, 'racks'), substationId).map((r) => [r.id, r]));
  const types = new Map(catalog.equipmentTypes.map((t) => [t.id, t]));
  const cats = new Map(catalog.categories.map((c) => [c.id, c]));
  const lastInspected = new Map<string, string>();
  for (const i of effectiveRows(s, 'inspections')) {
    const prev = lastInspected.get(i.equipmentId);
    if (!prev || i.inspectedAt > prev) lastInspected.set(i.equipmentId, i.inspectedAt);
  }
  const subName = s.saved.substations[substationId]?.name ?? '';
  return bySubstation(effectiveRows(s, 'equipment'), substationId).map((e) => {
    const t = types.get(e.typeId);
    return {
      id: e.id, substationId, substationName: subName, rackId: e.rackId, rackName: racks.get(e.rackId)?.name ?? '—',
      typeName: t?.name ?? '—', categoryName: (t && cats.get(t.categoryId)?.name) ?? '—', name: e.name, status: e.status,
      model: e.model, maker: e.maker, installDate: e.installDate, lastInspectedAt: lastInspected.get(e.id) ?? null,
    };
  });
}

export function rowsFromNode(rows: NodeEquipmentRow[]): StatusRow[] {
  return rows.map((r) => ({
    id: r.id, substationId: r.substationId, substationName: r.substationName, rackId: r.rackId, rackName: r.rackName,
    typeName: r.typeName, categoryName: r.categoryName, name: r.name, status: r.status,
    model: r.model, maker: r.maker, installDate: r.installDate, lastInspectedAt: r.lastInspectedAt,
  }));
}
```

3. 잇기 대화상자: 반대쪽 끝을 **검색 목록**에서 고른다(`endpointOptions` — `TableSearch` 로 거름, 묶음 머리 설비/회로/코어). 이미 쓰인 회로·코어 끝(`taken`)은 흐리게 + 고를 수 없음. 그다음 케이블 품목(Select — `isLinkMedium` 인 것만, **비워 둘 수 있다**), 길이(m), 이쪽·반대쪽 표기(설비 끝일 때만 입력칸).
4. 확인 전에 `validateState(toModelState(effective + 이 연결))` 로 미리 보고 흠이 있으면 그 문구를 띄우고 확인 비활성.
5. 확인 → `create('links', { id: newId(), substationId, cableTypeId, lengthM, spec: null, note: null, pathPoints: [], a: from(+표기), b: to(+표기), updatedAt: '' })`.

```ts
import { endRefKey, type LinkEndRef } from '@twin/core';
import { bySubstation, effectiveCircuits, effectiveRows, equipmentName, linesTouching } from '../../model/store/effective';
import type { WorkingCopyState } from '../../model/store/workingCopy';
import type { Link } from '../../model/types';

type S = Pick<WorkingCopyState, 'saved' | 'overlays'>;
export interface EndpointOption { ref: LinkEndRef; label: string; group: '설비' | '회로' | '코어'; taken: boolean }

const lineName = (s: S, lineId: string) => {
  const l = effectiveRows(s, 'fiberLines').find((x) => x.id === lineId);
  return l ? (l.name ?? `${l.aSubstationName}–${l.bSubstationName}`) : '선로';
};

export function endLabel(s: S, ref: LinkEndRef): string {
  switch (ref.kind) {
    case 'equipment': return [equipmentName(s, ref.equipmentId) ?? '—', ref.label].filter(Boolean).join(' ');
    case 'circuit': return `${equipmentName(s, ref.equipmentId) ?? '—'} 회로 ${ref.no}`;
    case 'core': return `${lineName(s, ref.lineId)} 코어 ${ref.no}`;
  }
}

export function endpointOptions(s: S, substationId: string): EndpointOption[] {
  const taken = new Set(effectiveRows(s, 'links').flatMap((l) => [l.a, l.b]).filter((r) => r.kind !== 'equipment').map(endRefKey));
  const out: EndpointOption[] = [];
  const eq = bySubstation(effectiveRows(s, 'equipment'), substationId);
  for (const e of eq) out.push({ ref: { kind: 'equipment', equipmentId: e.id }, label: e.name, group: '설비', taken: false });
  for (const e of eq) for (const c of effectiveCircuits(s, e.id)) {
    const ref: LinkEndRef = { kind: 'circuit', equipmentId: e.id, no: c.no };
    out.push({ ref, label: endLabel(s, ref), group: '회로', taken: taken.has(endRefKey(ref)) });
  }
  for (const l of linesTouching(s, substationId)) {
    const sides = ([['A', l.aSubstationId], ['B', l.bSubstationId]] as const).filter(([, sub]) => sub === substationId);
    for (const [side] of sides) for (let no = 1; no <= l.coreCount; no++) {
      const ref: LinkEndRef = { kind: 'core', lineId: l.id, no, side };
      out.push({ ref, label: endLabel(s, ref), group: '코어', taken: taken.has(endRefKey(ref)) });
    }
  }
  return out;
}

export function linksOfEquipment(s: S, equipmentId: string): Link[] {
  const touches = (r: LinkEndRef) => (r.kind === 'equipment' || r.kind === 'circuit') && r.equipmentId === equipmentId;
  return effectiveRows(s, 'links').filter((l) => touches(l.a) || touches(l.b));
}
```
